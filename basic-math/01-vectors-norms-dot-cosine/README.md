# 1장. 벡터와 행렬 연산 — 노름 · 정규화 · 내적 · 코사인 유사도

> 2026-08-05 학습 기록. 기초 수학(선형대수) 첫날 수업입니다. 숫자 묶음을 "모양이 있는 대상"(스칼라 · 벡터 · 행렬)으로 보고, 길이(노름)와 방향(단위벡터), 두 벡터가 얼마나 같은 방향인지(내적 · 코사인 유사도)를 실제 데이터(UCI Wine Quality, Online Retail)로 계산했습니다.

## 학습 목표

- 스칼라 · 벡터 · 행렬을 구분하고 데이터프레임의 한 행이 벡터, 전체가 행렬이라는 것을 shape으로 확인한다.
- L1 · L2 · L∞ 노름을 계산하고, 벡터를 길이로 나눠 방향만 남기는 정규화를 한다.
- 내적을 직접(`np.sum(a * b)`) 그리고 `np.dot` · `@`로 계산하고, 내적이 길이에 끌려가는 문제를 코사인 유사도로 해결한다.
- 행렬곱의 shape 규칙 `(m×n)(n×p) = (m×p)`을 쓰고, 선형층 `y = Wx + b`와 연결한다.

## 전체 흐름

```text
데이터프레임 X (6497, 11)
 ├─ 한 행 X.iloc[0] → 벡터 (11,)   한 칸 → 스칼라
 ├─ 길이(노름)   L1 · L2 · L∞
 ├─ 방향(정규화) x / ||x||  → 길이 1
 └─ 두 벡터 비교
      내적 a·b = Σ aᵢbᵢ           ← 길이에 끌려감
      코사인 = a·b / (||a|| ||b||)  ← 방향만 비교 (−1 ~ 1)
```

## 핵심 이론

### 1. 스칼라 · 벡터 · 행렬

| 이름 | 모양 | 예 |
| --- | --- | --- |
| 스칼라 | 숫자 하나 | 알코올 도수 `9.4`, 학습률 `0.001` |
| 벡터 | 순서 있는 숫자 목록 `(n,)` | 와인 한 병의 특징 11개 |
| 행렬 | 행×열 표 `(m, n)` | 와인 6497병 × 특징 11개 |

- 벡터는 두 얼굴이 있어요. 데이터로 보면 "특징을 한 줄에 모은 것", 기하로 보면 "원점에서 한 점으로 가는 화살표".
- 덧셈은 같은 위치끼리(차원이 같아야 함), 스칼라배는 모든 성분에 같은 수를 곱해요. 양수배는 방향 유지, 음수배는 방향 반전.

### 2. 노름과 정규화

```text
L1 = Σ|xᵢ|          L2 = √(Σxᵢ²)          L∞ = max|xᵢ|
단위벡터 x̂ = x / ||x||₂   (x ≠ 0)
```

- L2는 피타고라스 정리를 n차원으로 늘린 것. `[3, 4]`의 길이는 5, 단위벡터는 `[0.6, 0.8]`.
- 정규화는 **방향은 그대로 두고 길이만 1로** 맞춰요. 0벡터는 0으로 나눌 수 없어서 정규화할 수 없어요.

### 3. 내적과 코사인 유사도

```text
a·b = aᵀb = Σ aᵢbᵢ          (결과는 숫자 하나)
a·b = ||a|| ||b|| cos θ
cos θ = a·b / (||a|| ||b||)   (−1 ~ 1)
```

- 내적이 양수면 비슷한 방향, 0이면 직각, 음수면 반대.
- 코사인 유사도는 길이를 나눠서 **방향만** 비교해요. 그래서 구매량이 많은 고객이 무조건 "가깝다"고 나오는 내적의 문제를 해결해요.
- 투영: `proj_y(x) = (x·y / y·y) y` = x에서 y 방향 성분만 뽑기.

### 4. 행렬곱과 선형층

```text
A(m×n) · B(n×p) = C(m×p)       안쪽 n이 같아야 하고 바깥 m, p가 결과 shape
단일: y = Wx + b    W: (d_out × d_in)
배치: Y = XWᵀ + b   X: (B × d_in)
```

- 결과의 (i, j) 칸은 A의 i번째 행과 B의 j번째 열의 내적이에요.
- 일반적으로 `AB ≠ BA`. `(AB)ᵀ = BᵀAᵀ`처럼 전치는 순서가 뒤집혀요.

### 1-1 · 벡터, 노름, 정규화 (UCI Wine Quality)

```python
v1 = X.iloc[0].values            # (11,) 벡터

v2 = X.iloc[1].values
mean = (v1 + v2) * 0.5
V1 = 2 * v1
np.allclose(V1 / np.linalg.norm(V1), v1 / np.linalg.norm(v1))   # True → 2배해도 방향은 같다

L1, L2, Linf = (np.linalg.norm(v1, p) for p in (1, 2, np.inf))  # 69.5438 / 37.9191 / 34.0
L2C = np.sqrt(np.sum(v1 ** 2))                                   # 직접 계산도 37.9191

X5 = X.iloc[:5].values
X5_unit = X5 / np.linalg.norm(X5, axis=1, keepdims=True)         # 행마다 길이 1

```

### 1-2 · 내적과 코사인 (고객 60 × 상품 150 구매량 행렬)

```python
a, b = M[0], M[1]
np.sum(a * b) == np.dot(a, b)    # 31537526.0, 결과 타입은 numpy.float64 (숫자 하나)

dots = M @ a                     # 모든 고객과 a의 내적 한 번에 (60,)
order = np.argsort(dots)[::-1]   # 1위는 자기 자신 (= |a|²)
top5 = order[1:6]                # 자신 빼고 상위 5명

def cosine(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

cosine(a, b)        # 0.5495
cosine(a, a)        # 1.0000000000000002 (부동소수점 오차)
cosine(a, 3 * a)    # 1.0 → 길이를 3배 해도 방향이 같으면 1
cosine([1, 0, 2], [0, 5, 0])   # 0.0 → 겹치는 상품이 없으면 직각
```

## 질문과 새로 알게 된 점

- **내적 1위는 항상 자기 자신**이에요. `dots[0] = |a|²`라서 상위 고객을 찾을 땐 `order[1:6]`처럼 자신을 빼야 해요.
- 내적 상위 고객은 **총 구매량이 많은 고객**이 많았어요(평균 총구매량 12,354 vs 상위권 17,000~25,000). 내적은 길이에 끌려가서 "취향이 비슷한 고객"을 찾으려면 코사인이 맞아요.
- `cosine(a, a)`가 정확히 1이 아니라 `1.0000000000000002`인 건 부동소수점 오차. 그래서 비교할 땐 `np.isclose` / `np.allclose`를 써요.
- `axis=1, keepdims=True`: 행마다 길이를 구하고 `(5, 1)` 모양을 유지해야 `(5, 11)`과 나눌 때 broadcasting이 맞아요.
- 유사도 0은 "관계가 없다"가 아니라 **기하학적으로 직교**한다는 뜻이에요.
- 이 개념들이 이후에 그대로 다시 나왔어요: Attention score = Q와 K의 내적(딥러닝 심화 3장), 임베딩 검색 = 정규화 후 내적 = 코사인(RAG 4·5장).

### 1-Q2. 내적 vs 코사인 (1-2)

고객 a와 비슷한 **취향**의 고객을 찾으려 한다. 구매량이 아주 많은 고객이 상위에 몰리는 문제를 줄이려면?

① 내적을 그대로 쓴다  
② L1 노름이 큰 순서로 고른다  
③ 내적을 두 벡터 길이의 곱으로 나눈 코사인 유사도를 쓴다  
④ 내적에 구매량을 한 번 더 곱한다

<details>
<summary>정답 보기</summary>

**③** — 내적은 `||a|| ||b|| cos θ`라 길이가 큰 벡터가 유리해요. 코사인은 길이를 나눠 방향만 비교하므로 `cosine(a, 3a) = 1`처럼 양이 달라도 같은 취향이면 1이 나와요.

</details>

### 1-Q3. 행렬곱 shape (1-3)

입력 5개를 받아 출력 3개를 내는 선형층 `y = Wx`에서 W의 shape과, 배치 입력 `X: (32, 5)`에 대한 출력 shape은?

① W `(5, 3)`, 출력 `(5, 32)`  
② W `(3, 3)`, 출력 `(32, 5)`  
③ W `(5, 5)`, 출력 `(32, 3)`  
④ W `(3, 5)`, 출력 `(32, 3)`

<details>
<summary>정답 보기</summary>

**④** — `y = Wx` 기준 W는 `(d_out, d_in) = (3, 5)`. 배치는 `Y = XWᵀ`라 `(32, 5)(5, 3) = (32, 3)`. PyTorch `nn.Linear(5, 3).weight`도 `(3, 5)`예요.

</details>

### 1-Q4. 서술형 — 정규화한 뒤의 내적

<details>
<summary>예시 답안</summary>

코사인 = 내적 ÷ (두 길이의 곱)인데, 길이가 모두 1이면 분모가 1 × 1 = 1이라 내적이 곧 코사인이 돼요. 그래서 문서 벡터를 미리 정규화해 행렬 하나로 저장해 두면, 질문 벡터 하나와 `vectors @ query` 행렬곱 한 번으로 모든 문서의 코사인 점수를 얻을 수 있어요. RAG 4장의 Dense 검색과 Qdrant `COSINE`, FAISS `IndexFlatIP`가 이 원리를 써요.

</details>
