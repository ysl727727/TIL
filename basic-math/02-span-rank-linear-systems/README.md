## 학습 목표

- 목표 벡터를 다른 벡터들의 선형결합으로 표현하고 span의 의미를 설명한다.

- 문장 조건을 `Ax = b`로 바꿔 `np.linalg.solve`로 풀고 `A @ x`로 검산한다. 역행렬 대신 `solve`를 쓰는 이유를 조건수로 설명한다.

## 전체 흐름

```text
행렬 A = 공간 변환   (열 = 표준기저 e₁, e₂가 옮겨 간 위치)
 ├─ 선형결합 c₁v₁ + c₂v₂ → 만들 수 있는 전체 = span
 ├─ 독립인가?  rank(A) = 독립인 컬럼 수
 │     중복 컬럼이 있으면 Ax = 0에 0 아닌 해 → 영공간 차원 = 컬럼 수 − rank
 └─ Ax = b 풀기
       rank(A) < rank([A|b]) → 해 없음
       rank(A) = 변수 수      → 유일해  → solve
       그 외                   → 무한해
```

## 핵심 이론

### 1. 선형 변환

- `T(ax + by) = aT(x) + bT(y)`를 만족하면 선형. 원점은 항상 원점으로 가요.
- 행렬의 **열**이 표준기저가 이동한 위치예요. `A = [[2,1],[0,1]]`이면 e₁ → `[2,0]`, e₂ → `[1,1]`.
- `y = Ax + b`(b ≠ 0)는 엄밀히는 아핀 변환이에요. 딥러닝에서는 관습적으로 Linear layer라고 불러요.
- 활성화 함수 없이 선형층을 쌓으면 `W₂(W₁x) = Wx` 하나로 합쳐져요 → 딥러닝 기초 4장 비선형성으로 이어짐.

### 2. span · 선형독립 · rank

- **span** = 벡터들의 모든 선형결합의 집합. 평행한 두 벡터의 span은 평면이 아니라 **직선**이에요.
- **선형독립** = `c₁v₁ + … + cₖvₖ = 0`을 만드는 방법이 모두 0뿐. 하나라도 다른 벡터들의 조합이면 종속(중복 정보).
- **rank** = 열공간의 차원 = 서로 독립인 컬럼 수. 컬럼이 많아도 rank가 그대로면 새 정보가 없어요.
- **영공간** = `Ax = 0`을 만족하는 x들. 0이 아닌 해가 있으면 컬럼 중복이 있다는 뜻이고, 그 x의 계수가 "어떤 컬럼이 어떤 조합으로 중복인지"를 알려 줘요.
- rank–nullity: **컬럼 수 = rank + 영공간 차원**.

### 3. Ax = b와 수치 계산

- 연립방정식은 계수를 행렬 A, 미지수를 x, 상수를 b로 묶어 `Ax = b`로 써요. 행 = 방정식, 열 = 미지수.
- 해의 세 경우: 유일해 / 무한해(자유변수) / 해 없음(`[0 … 0 | c]` 모순 행).
- 이론은 `x = A⁻¹b`지만 실무는 `np.linalg.solve(A, b)`. 역행렬을 따로 만들지 않아 계산량이 적고 **수치적으로 안정적**이에요.
- **조건수**(`np.linalg.cond`)가 크면 b를 아주 조금만 바꿔도 해가 크게 움직여요(나쁜 조건 행렬).
- 과잉결정(방정식 > 미지수)이면 정확한 해가 없어서 오차 제곱합을 최소로 하는 **최소제곱해**(`lstsq`, 정규방정식 `AᵀAβ = Aᵀb`)를 구해요 → 선형회귀와 같은 구조.

## 내가 작성한 코드

### 2-2 · 선형결합 계수 찾기

```python
v1, v2 = np.array([1.0, 1.0]), np.array([1.0, -1.0])
target = np.array([3.0, 5.0])
B = np.column_stack([v1, v2])                 # v1, v2를 열로 묶음
coeffs, *_ = np.linalg.lstsq(B, target, rcond=None)
# 계수 [4. -1.] → 복원 [3. 5.] → 일치 True

w1 = np.array([1.0, 2.0]); w2 = 2 * w1        # 평행한 두 벡터
W = np.column_stack([w1, w2])                 # rank 1
# 목표 [3, 5] → 복원 [2.6, 5.2], 오차 0.447 (직선 밖이라 못 만듦)
# 목표 [2, 4] → 복원 [2, 4],   오차 0.0   (직선 위라 만들 수 있음)
```

### 2-2 · 센서 5개, 진짜 정보는 몇 개? (AI4I 2020, 10000×5)

```python
np.linalg.matrix_rank(A)          # 5 = 최대 rank (풀랭크)

# 공기 온도–공정 온도 0.876, 회전 속도–토크 −0.875 인데도 rank는 5

A_dep  = np.column_stack([A, A[:, 0] * 2, A[:, 1] + A[:, 2]])   # 종속 컬럼 2개 추가

# 원본 5컬럼 rank 5 / 종속 추가 7컬럼 rank 5 / 난수 추가 6컬럼 rank 6
```

### 2-2 심화 · 영공간으로 중복 관계 찾기

```python
c1 = np.zeros(7); c1[0], c1[-2] = 2.0, -1.0              # 2·col0 − col5 = 0
c2 = np.zeros(7); c2[1], c2[2], c2[-1] = 1.0, 1.0, -1.0  # col1 + col2 − col6 = 0
np.linalg.norm(A_dep @ c1), np.linalg.norm(A_dep @ c2)   # 0.0, 0.0
# A_dep: 컬럼 7, rank 5, 영공간 차원 2  /  A: 컬럼 5, rank 5, 영공간 차원 0
```

### 2-3 · 와인 배합을 Ax = b로

```python
A = np.array([[2.0, 1.0], [1.0, 3.0]])     # 알코올 기여 / 산도 기여
b = np.array([8.0, 13.0])
x = np.linalg.solve(A, b)                  # [2.2, 3.6]
np.allclose(A @ x, b)                      # True (검산)

A2 = np.array([[2.0, 1.0], [2.000001, 1.0000004]])   # 거의 종속
np.linalg.cond(A)    # 2.62
np.linalg.cond(A2)   # 50,000,024  → 나쁜 조건
np.linalg.solve(A2, [8.0, 8.000002])     # [-6, 20]
np.linalg.solve(A2, [8.0, 8.0000021])    # [-5.5, 19]  ← b를 0.0000001 바꿨는데 해가 0.5씩 움직임
```

## 질문과 새로 알게 된 점

- **상관 0.876인데 왜 rank가 안 깎이지?** → 상관이 높다는 건 "대충 같은 방향"이지 "정확히 다른 컬럼으로 계산된다"가 아니에요. rank가 실제로 깎이려면 상관이 **정확히 ±1.0**이어야 해요. 대신 높은 상관은 **다중공선성** 문제를 만들어요(역행렬은 있지만 조건수가 커서 회귀계수가 불안정). "rank가 안 깎임 = 문제없음"이 아니에요.
- **"컬럼이 많다 = 정보가 많다"가 아니다.** 종속 컬럼 2개를 붙여도 rank는 5 그대로, 난수 컬럼은 기존 컬럼으로 설명이 안 돼서 rank가 1 늘어요.
- 표준기저 `[1,0]`, `[0,1]`로 하면 계수가 목표 벡터 성분 그대로라 의미가 없어요. 기저를 바꿔야 계수를 "구하는" 계산이 의미를 가져요.
- `coeffs, *_ = np.linalg.lstsq(...)`: `lstsq`는 값을 4개 돌려주는데 첫 번째(계수)만 쓰고 나머지는 `*_`로 버리는 언패킹.
- `np.linalg.solve`는 **정사각행렬이면서 해가 유일할 때만** 써요. 그 외에는 `LinAlgError` → 해의 종류부터 판별.

② `inv`는 정사각행렬이 아니어도 동작해서

④ `solve`는 조건수와 상관없이 항상 정확해서
