# 3·4장. 고유값 · PCA · 특이값 분해(SVD)

> 2026-08-07 학습 기록. 기초 수학 3일차 수업입니다. 변환해도 방향이 바뀌지 않는 벡터(고유벡터)와 그 배율(고유값), 공분산의 고유벡터로 데이터를 가장 넓게 퍼진 방향으로 줄이는 PCA, 그리고 정사각이 아니어도 항상 되는 분해 SVD를 고객×상품 구매 행렬로 실습했습니다.

## 학습 목표

- `Av = λv`의 의미(방향 유지, λ배)를 설명하고 `det(A − λI) = 0`으로 고유값을 구하는 원리를 안다.
- PCA 절차(중심화 → 공분산 → 고유분해 → 상위 k개 → 투영)와 설명분산비를 설명한다.
- `np.linalg.svd`로 `U`, `S`, `Vt`를 구하고 각 shape과 역할을 설명한다. 축소형/전체형 차이를 안다.
- 특이값 = `MᵀM` 고유값의 제곱근임을 확인하고, 수치 오차로 생기는 음수 고유값에 `clip`이 필요한 이유를 안다.
- 잘린 SVD(상위 k개)가 최적의 저랭크 근사라는 것과 LoRA의 저랭크 아이디어를 연결한다.

## 전체 흐름

```text
고유분해 (정사각·대칭일 때 깔끔)       SVD (어떤 행렬이든 항상 가능)
 A v = λ v                              M = U Σ Vᵀ
 A = P Λ P⁻¹                            U: 행 쪽 방향 (60×40)
   │                                    Σ: 중요도 (특이값, 내림차순)
   ▼                                    Vᵀ: 열 쪽 방향 (40×40)
 PCA = 공분산 C의 고유벡터                  │
   중심화 → C → 고유값 큰 순 k개 → 투영      ▼
                                        특이값² = MᵀM의 고유값
                                        상위 k개만 → 저랭크 근사 (압축, LoRA)
```

## 핵심 이론

### 1. 고유값과 고유벡터 (3-1)

```text
A v = λ v   (v ≠ 0)
(A − λI) v = 0 에 0 아닌 해가 있으려면 det(A − λI) = 0
```

- 대부분의 벡터는 변환 뒤 방향이 바뀌는데, 고유벡터는 **방향이 그대로**이고 길이(와 부호)만 λ배.
- |λ| > 1 확대, 0 < |λ| < 1 축소, λ < 0 반전, **λ = 0이면 그 방향 정보가 사라짐** → 역행렬 없음.
- `A = diag(3, 2)`: e₁ 방향 3배, e₂ 방향 2배.
- 딥러닝 연결: 같은 변환을 반복(`Aᵏx`)하면 가장 큰 고유값 방향이 지배 → 신호 폭발·소실, RNN 장기 거동.

### 2. 대각화와 PCA (3-2)

```text
A = P Λ P⁻¹   →   Aᵏ = P Λᵏ P⁻¹
PCA: Xc = X − μ  →  C = XcᵀXc / (N−1)  →  C의 고유값·고유벡터
     →  큰 고유값 순 k개로 W  →  Z = Xc W
설명분산비 = (λ₁ + … + λₖ) / Σλᵢ
```

- PCA는 분산을 가장 많이 보존하는 **서로 직교한** 방향을 찾아요. 고유값 = 그 방향의 분산.
- 평균을 빼지 않으면 원점과의 거리가 주성분을 왜곡해요. 단위가 다르면 표준화도.
- 라벨을 안 쓰는 비지도 방법이라 "분산이 크다 = 과제에 중요하다"는 보장은 없어요.

### 3. 직교성과 최소제곱 (3-3)

- 직교행렬 `QᵀQ = I`는 길이와 각도를 보존하고 `Q⁻¹ = Qᵀ`.
- 최소제곱해는 b를 A의 열공간에 **투영**한 것. 정규방정식 `AᵀAx = Aᵀb`. MSE 회귀 학습과 같은 구조예요.

### 4. SVD (4-1 · 4-2)

```text
M (m×n) = U (m×r) · Σ (r×r) · Vᵀ (r×n)      r = min(m, n)  (축소형)
특이값 σᵢ = √(MᵀM의 고유값)
```

- 정사각이 아니어도, 대칭이 아니어도 SVD는 **항상 존재**해요. 고유분해와 가장 큰 차이.
- `U`, `V`의 열은 정규직교(`UᵀU = I`, `VᵀV = I`). `S`는 대각 원소만 의미가 있어서 NumPy가 **1차원 배열**로 줘요(`np.diag(S)`로 행렬화).
- 상위 k개 특이값만 남긴 잘린 SVD가 같은 rank 중 **가장 오차가 작은 근사**(Eckart–Young) → 압축, 노이즈 제거, 추천.
- PCA = 중심화한 데이터의 SVD. 공분산을 직접 만들지 않아도 돼요.
- 딥러닝 연결: **LoRA**는 큰 가중치 업데이트를 저랭크 두 행렬의 곱 `BA`로 제한해요(딥러닝 심화 7장).

## 내가 작성한 코드

### 4-1 · 고객 60 × 상품 40 행렬의 SVD

```python
U, S, Vt = np.linalg.svd(M, full_matrices=False)
Uf, Sf, Vtf = np.linalg.svd(M, full_matrices=True)
# M (60, 40) → 축소형 U (60, 40), S (40,), Vt (40, 40)
#              전체형 U (60, 60), S (40,), Vt (40, 40)
S[:5]                              # [14845.4, 13351.8, 12540.3, 11638.5, 10191.5]
bool(np.all(np.diff(S) <= 1e-9))   # True → 내림차순

np.allclose(U.T @ U, np.eye(U.shape[1]))     # True (직교)
M_hat = U @ np.diag(S) @ Vt                  # 복원은 반드시 축소형으로
np.linalg.norm(M - M_hat)                    # 7.8e-11, 상대 오차 2.1e-15
```

### 4-1 · 특이값과 MᵀM 고유값

```python
M2 = M.T @ M                                       # (40, 40), 대칭 True
eigvals = np.linalg.eigvalsh(M2)
eigvals = np.sort(np.clip(eigvals, 0, None))[::-1] # 음수 오차 제거 후 내림차순
np.sqrt(eigvals)[:5]                               # S[:5]와 같음, 최대 차이 3.1e-11

C = rng.normal(0, 1, (60, 5)); P = rng.normal(0, 1, (5, 40))
R = C @ P                                          # rank 5 (60×40인데 정보는 5개)
np.sum(np.linalg.eigvalsh(R.T @ R) < 0)            # 18 ← 이론상 0이어야 할 고유값이 수치 오차로 음수
```

## 질문과 새로 알게 된 점

- **`full_matrices=True`면 U가 (60, 60)**까지 채워지지만 뒤쪽 20열은 복원에 안 쓰여요. 이걸로 `U @ np.diag(S) @ Vt`를 하면 `(60,60)(40,40)`이라 shape 오류 → 복원은 축소형으로.
- **랭크가 부족한 행렬은 `RᵀR`의 고유값 중 이론상 0인 것들이 `-1e-13`처럼 음수로** 나와요(18개). 여기에 바로 `np.sqrt`를 하면 `nan` → 그래서 제곱근 전에 `np.clip(…, 0, None)`.
- 실데이터 M은 최소 고유값도 충분히 커서 clip이 있으나 없으나 같았어요. clip은 **랭크 결손이 있을 때** 진짜 필요해요.
- `eigvalsh`는 대칭행렬 전용이라 실수 고유값을 오름차순으로 줘요 → `[::-1]`로 뒤집어 특이값 순서와 맞춤.
- PCA 실습(3-2)은 sklearn 코드 초안만 쓰고 실행하지 못했어요(`X_st` 오타, 위 입력 미작성).

### 3-Q1. 고유값 0 (3-1)

행렬 A에 고유값 0인 고유벡터가 있다. 맞는 것은?

① A는 항상 역행렬이 있다  
② 그 방향의 벡터가 0으로 보내져 정보가 사라지므로 A는 역행렬이 없다  
③ 그 고유벡터는 0벡터다  
④ 모든 고유값이 0이라는 뜻이다

<details>
<summary>정답 보기</summary>

**②** — `Av = 0·v = 0`이라 v 방향이 납작하게 사라져요. 되돌릴 수 없으니 비가역(행렬식 0). 고유벡터는 정의상 0벡터가 아니에요.

</details>

② U `(40, 60)`, S `(40,)`, Vt `(60, 40)`

### 3-Q4. 서술형 — 고유분해 대신 SVD

고객×상품 구매 행렬(60×40)을 분석할 때 고유분해 대신 SVD를 쓰는 이유와, 상위 k개 특이값만 남기는 것이 무슨 의미인지 쓰세요.

<details>
<summary>예시 답안</summary>

고유분해는 정사각행렬에서만 정의되고 대칭이 아니면 실수·직교 분해가 보장되지 않는데, 구매 행렬은 60×40으로 정사각이 아니에요. SVD는 어떤 행렬이든 항상 `UΣVᵀ`로 분해되고 U·V가 직교라 해석이 쉬워요. 특이값은 각 방향(취향 축)의 중요도라, 상위 k개만 남기면 고객·상품을 k개의 잠재 취향으로 요약한 저랭크 근사가 되고, 같은 rank 중 오차가 가장 작아요. 압축·노이즈 제거·추천에 쓰이고, LoRA의 "업데이트는 저랭크로 충분하다"는 생각과 같은 뿌리예요.

</details>
