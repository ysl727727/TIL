## 오늘 배운 것
- 자료형은 `int` · `float` · `str` · `bool`. `type()`으로 확인한다. `10 + 3.5`는 `float`, `'10' == 10`은 `False`.
- 변수 이름은 숫자로 시작할 수 없고(`1st_place` ❌), 예약어(`for`)도 안 된다. `a, b = b, a`로 한 줄에 값을 바꾼다.
- `input()`은 **항상 문자열**을 돌려준다. 숫자로 쓰려면 `int(input())`, 여러 개는 `map(int, input().split())`.
- `print`는 쉼표로 이으면 공백, `sep`·`end`로 구분자와 끝 글자를 바꾼다. f-string `f"{name}"`.
- 문자열 슬라이싱 `[start:end:step]`에서 **end는 포함하지 않는다.** `[::-1]`은 거꾸로.
- `find`는 없으면 -1, `index`는 없으면 `ValueError`. `split`은 리스트, `join`은 리스트를 문자열로.
- 문자열은 바꿀 수 없다(`s[0] = 'h'` ❌) → `'h' + s[1:]`처럼 새로 만든다.
- 조건문은 위에서부터 **첫 번째로 맞는 길 하나만** 실행. 예외(범위 밖 입력)부터 먼저 거른다.

## 왜 중요한가
- 과정의 첫 코드였다. 여기서 헷갈린 `input` 타입, 슬라이스 끝, 조건 순서가 이후 보강 수업(1주 1일·2일)에서도 계속 다시 나왔다.

## 코드/예시
```python
# 숫자만 int로 바꾸기 (입출력 실습 1+)
name, age = map(lambda x: int(x) if x.isdigit() else x,
                input("이름과 나이를 입력하세요: ").split())

# 윤년
if (year % 4 == 0) and (year % 100 != 0 or year % 400 == 0):
    print("윤년입니다.")

# 삼각형: 직각을 먼저 판정해야 3 4 5가 직각삼각형으로 나온다
if a**2 + b**2 == c**2 or b**2 + c**2 == a**2 or a**2 + c**2 == b**2:
    print("직각삼각형")
elif a == b == c:
    print("정삼각형")
```

## 헷갈렸던 부분 & 해결
- 삼각형 첫 버전은 `a != b != c`를 직각보다 먼저 검사해서 `3 4 5`가 "일반 삼각형"이 됐다 → 조건 순서를 바꿔 해결. `a != b != c`는 a와 c를 비교하지도 않는다.
- `bool(input())`은 "False"를 넣어도 `True`(빈 문자열만 False) → 입력 글자를 직접 비교해야 한다.
- 뒤 3글자를 `[-4:-1]`로 써서 `Python`이 `tho`가 됐다 → `[-3:]`.
- `"apple, banana".split(",")`은 앞 공백이 남는다 → `split(", ")`.
- `prnt` 오타로 `NameError`.
