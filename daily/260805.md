> 기초 수학 1장 · 벡터와 행렬 연산 (노름 · 정규화 · 내적 · 코사인) / 파이썬 베이직반 반복문

## 오늘 배운 것
- 스칼라는 숫자 하나, 벡터는 순서 있는 숫자 목록, 행렬은 행×열 표. 데이터프레임 한 행 = 벡터, 전체 = 행렬.
- L1 = Σ|xᵢ|, L2 = √Σxᵢ², L∞ = max|xᵢ|. 벡터를 L2로 나누면 **방향은 그대로, 길이만 1**(정규화).
- 2배 한 벡터를 정규화하면 원래 벡터의 정규화와 같다 → 스칼라배는 방향을 바꾸지 않는다.
- 내적 `a·b = Σaᵢbᵢ`는 숫자 하나. `a·b = ||a|| ||b|| cos θ`.
- 코사인 유사도 = 내적 ÷ 길이의 곱 → **방향만** 비교(−1 ~ 1). 0이면 직교.
- 행렬곱 `(m×n)(n×p) = (m×p)`, 안쪽이 같아야 한다. 선형층은 `y = Wx + b`.

## 왜 중요한가
- 내적은 길이에 끌려간다. 구매량이 많은 고객이 무조건 "가깝게" 나와서, 취향이 비슷한 고객을 찾으려면 코사인을 써야 한다.
- 이 계산이 나중에 그대로 다시 나왔다: Attention score = Q·K 내적, 임베딩 검색 = 정규화 후 내적 = 코사인.

## 코드/예시
```python
X5_unit = X5 / np.linalg.norm(X5, axis=1, keepdims=True)   # 행마다 길이 1

dots = M @ a                         # 모든 고객과 a의 내적 (60,)
order = np.argsort(dots)[::-1]
top5 = order[1:6]                    # 1위는 자기 자신이라 빼기

def cosine(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
cosine(a, 3 * a)                     # 1.0  → 양이 달라도 방향이 같으면 1
cosine([1, 0, 2], [0, 5, 0])         # 0.0  → 겹치는 상품이 없으면 직교
```

## 헷갈렸던 부분 & 해결
- 내적 1위가 항상 자기 자신(`|a|²`)이라 상위 고객을 볼 때 `order[1:6]`로 빼야 했다.
- `cosine(a, a)`가 `1.0000000000000002` → 부동소수점 오차라 비교는 `np.isclose`.
- `axis=1, keepdims=True`를 써야 `(5, 1)` 모양이 유지돼서 `(5, 11)`과 나눌 수 있다.
- 1-2 심화와 1-3(행렬 연산 실습)은 데이터 준비까지만 했다.
- 반복문 미니과제는 받았지만 아직 손대지 못했다.
