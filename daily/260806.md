> 기초 수학 2장 · 선형 변환과 연립방정식 (선형결합 · span · rank · 영공간 · Ax = b)

## 오늘 배운 것
- 행렬은 공간을 바꾸는 변환이다. 행렬의 **열** = 표준기저 e₁, e₂가 옮겨 간 위치.
- 활성화 함수 없이 선형층을 쌓으면 `W₂(W₁x) = Wx` 하나로 합쳐진다.
- span = 벡터들의 모든 선형결합. 평행한 두 벡터의 span은 평면이 아니라 직선.
- rank = 서로 독립인 컬럼 수(열공간의 차원). 컬럼 수 = rank + 영공간 차원.
- `Ax = 0`의 0이 아닌 해(영공간)가 "어떤 컬럼이 어떤 조합으로 중복인지"를 알려 준다.
- 연립방정식은 `Ax = b`로 묶어 `np.linalg.solve`로 풀고 `A @ x`로 검산한다. 해는 유일해 / 무한해 / 해 없음.
- 조건수가 크면 b를 아주 조금만 바꿔도 해가 크게 움직인다.

## 왜 중요한가
- **"컬럼이 많다 = 정보가 많다"가 아니다.** 센서 5개에 종속 컬럼 2개를 붙여도 rank는 5, 난수 컬럼은 rank를 1 올린다. 정보량의 기준은 rank.
- 역행렬을 직접 구하지 않고 `solve`를 쓰는 이유(계산량·수치 안정성)가 실무 습관이 됐다.

## 코드/예시
```python
B = np.column_stack([v1, v2])
coeffs, *_ = np.linalg.lstsq(B, target, rcond=None)   # [4, -1] → [3, 5] 복원

A_dep = np.column_stack([A, A[:, 0] * 2, A[:, 1] + A[:, 2]])
np.linalg.matrix_rank(A_dep)          # 7컬럼인데 rank 5

c1 = np.zeros(7); c1[0], c1[-2] = 2.0, -1.0
np.linalg.norm(A_dep @ c1)            # 0.0 → "0번 × 2 = 5번" 관계 확인

np.linalg.cond(A2)                    # 50,000,024
np.linalg.solve(A2, [8.0, 8.000002])  # [-6, 20]
np.linalg.solve(A2, [8.0, 8.0000021]) # [-5.5, 19]  ← b를 1e-7 바꿨는데 해가 크게 이동
```

## 헷갈렸던 부분 & 해결
- 공기 온도–공정 온도 상관이 0.876인데 rank가 안 깎였다 → rank가 줄려면 상관이 **정확히 ±1**이어야 한다. 대신 높은 상관은 다중공선성(조건수↑, 회귀계수 불안정)을 만든다.
- 배합 결과를 출력하면서 원액 B 양 자리에 `b[1]`(상수항 13.0)을 써 버렸다 → `x[1]`.
- `coeffs, *_ = …`: 반환값 4개 중 첫 번째만 쓰고 나머지는 `*_`로 버리는 언패킹.
- 2-3의 "해의 세 경우 판별"(문제 2-1)부터는 못 끝냈다.
