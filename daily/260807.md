> 기초 수학 3장 · 고유값·고유벡터와 PCA / 4장 · 특이값 분해(SVD)

## 오늘 배운 것
- 고유벡터는 변환해도 **방향이 그대로**이고 길이만 λ배가 되는 벡터: `Av = λv`. `det(A − λI) = 0`으로 λ를 구한다.
- λ = 0이면 그 방향 정보가 사라져서 역행렬이 없다.
- PCA = 평균을 빼고 → 공분산 → 고유값이 큰 방향 k개 → 투영. 고유값 = 그 방향의 분산, 설명분산비 = 상위 k개 합 ÷ 전체.
- SVD `M = UΣVᵀ`는 정사각이 아니어도, 대칭이 아니어도 **항상** 된다.
- 특이값 = `MᵀM` 고유값의 제곱근. 상위 k개만 남기면 같은 rank 중 가장 오차가 작은 근사(압축, LoRA의 저랭크 아이디어).

## 왜 중요한가
- 고객×상품 구매 행렬(60×40)처럼 정사각이 아닌 실제 데이터는 고유분해 대신 SVD로 분석한다.
- "업데이트는 저랭크로 충분하다"는 생각이 나중에 딥러닝 심화 7장 LoRA(`h = Wx + BAx`)로 그대로 이어졌다.

## 코드/예시
```python
U, S, Vt = np.linalg.svd(M, full_matrices=False)   # (60,40) (40,) (40,40)
M_hat = U @ np.diag(S) @ Vt
np.linalg.norm(M - M_hat)                          # 7.8e-11 → 완전 복원

eig = np.linalg.eigvalsh(M.T @ M)
np.sqrt(np.sort(np.clip(eig, 0, None))[::-1])[:5]  # = S[:5]

R = C @ P                                          # (60,5)(5,40) → rank 5
np.sum(np.linalg.eigvalsh(R.T @ R) < 0)            # 18개가 음수 (수치 오차)
```

## 헷갈렸던 부분 & 해결
- `full_matrices=True`면 U가 `(60, 60)`이라 `U @ diag(S) @ Vt`가 shape 오류 → 복원은 축소형으로.
- `S`가 행렬이 아니라 1차원 배열로 나오는 이유: 대각 원소만 의미가 있어서. 행렬로 쓰려면 `np.diag(S)`.
- 랭크가 부족한 행렬의 `RᵀR`은 이론상 0인 고유값이 `-1e-13`처럼 음수로 나와서, 제곱근 전에 `clip`을 안 하면 `nan`이 된다.
- PCA 실습(sklearn)은 초안만 쓰고 실행하지 못했다(`X_st` 오타).
