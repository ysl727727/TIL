## 오늘 배운 것
- **배깅**은 서로 다른 bootstrap 표본으로 여러 모델을 따로 학습하고 예측을 합친다.
- **랜덤포레스트**는 행 표본 + 분할 후보 특성에 무작위성을 더해서 나무끼리 덜 비슷하게 만든다.
- OOB 평가는 빠른 내부 점검용이고 validation을 대신하지 않는다.
- **부스팅**은 지금까지의 앙상블이 틀린 부분을 다음 약한 모델이 순서대로 보완한다. Gradient Boosting은 손실 함수의 negative gradient를 학습한다.
- `learning_rate`와 반복 수는 같이 조정해야 하고, best iteration과 early stopping으로 멈춘 iteration은 다를 수 있다.
- 특성 중요도는 방법마다 답하는 질문이 다르다.
  - MDI: 트리 분할에서 불순도를 얼마나 줄였나
  - Permutation importance: validation 피처를 섞으면 성능이 얼마나 떨어지나
  - SHAP: 기준값에서 모델 출력까지 피처별 기여를 어떻게 나누나 (인과관계 증명은 아님)

## 왜 중요한가
- 후보 모델은 같은 fold, 같은 전처리, 같은 지표로 비교해야 공정하다. 평균 점수뿐 아니라 fold별 변동, 학습 시간, 운영 비용도 같이 봐야 한다.
- Dummy를 같이 넣어 "복잡한 모델이 단순 기준선보다 실제로 나은지"를 확인하는 습관이 생겼다.

## 코드/예시
```python
models = {
    "dummy": DummyClassifier(strategy="prior"),
    "tree": DecisionTreeClassifier(random_state=SEED),
    "forest": RandomForestClassifier(
        n_estimators=300, random_state=SEED,
        class_weight="balanced", max_features="sqrt",
    ),
}
table, selected_name, fitted_models = compare_ensemble_candidates(
    models, X_train, y_train, X_valid, y_valid
)
```

| 모델 | AP | F1 | Recall |
| --- | ---: | ---: | ---: |
| Random Forest | 0.9968 | 0.9524 | 0.9302 |
| Decision Tree | 0.8834 | 0.9157 | 0.8837 |
| Dummy | 0.3772 | 0.0000 | 0.0000 |

- 한 번의 고정된 분할 결과라 "랜덤포레스트가 항상 낫다"는 뜻은 아니다.
