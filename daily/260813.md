## 오늘 배운 것
- **편향**은 모델이 반복해서 비슷한 방향으로 빗나가는 정도, **분산**은 학습 데이터가 바뀔 때 예측이 흔들리는 정도다.
- train·validation 둘 다 낮으면 과소적합, train만 높으면 과적합을 의심한다. 점수 하나로 단정하지 말고 데이터 분포, 라벨 오류, 누수도 같이 본다.
- 곡선 두 개는 바꾸는 대상이 다르다.

| 곡선 | 바꾸는 것 | 질문 |
| --- | --- | --- |
| Learning curve | 훈련 샘플 수 | 데이터를 더 모을 가치가 있나 |
| Validation curve | 모델 복잡도·하이퍼파라미터 | 어느 복잡도가 적절한가 |

- gap이 작다고 좋은 모델이 아니다. 둘 다 낮으면 gap이 작아도 과소적합이다.
- **규제**: `손실 = 예측 오차 + alpha × 계수 벌점`. alpha가 크면 규제가 강하다.
  - Ridge(L2): 계수를 부드럽게 줄임
  - Lasso(L1): 일부 계수를 정확히 0으로
  - ElasticNet(L1 + L2): 선택 + 안정적인 축소
- 규제는 계수 크기로 벌점을 주니까 스케일을 먼저 맞춘다. `StandardScaler`를 `Pipeline`에 넣으면 fold마다 train으로만 학습돼서 누수가 없다.

## 왜 중요한가
- 과적합·과소적합을 "느낌"이 아니라 곡선과 점수로 진단해야 다음에 데이터를 늘릴지, 모델을 바꿀지 정할 수 있다.
- 세 규제 모델을 비교할 때도 같은 Dev·같은 fold·같은 전처리·같은 지표로 alpha를 고르고, 하나만 Test에서 평가해야 한다.

## 코드/예시
```text
regularized loss = prediction error + alpha × coefficient penalty
Pipeline([StandardScaler(), Ridge(alpha)])   ← fold마다 train으로만 scaler fit
```
