> 딥러닝 기초 6장 · Autograd와 안전한 평가 (6-1 ~ 6-5)

## 오늘 배운 것
- forward는 입력 → Loss 방향으로 값을 계산하고, backward는 Loss → parameter 방향으로 local gradient를 곱해 간다(Chain Rule).
  - `x=2, w=3, b=1` → `z=7`, `loss=z²` → `d(loss)/dw = 2z × x = 28`
- `requires_grad=True`에서 시작한 연산은 그래프에 기록된다. weight·bias 같은 **leaf**는 `.grad`를 저장하고, 중간 결과(non-leaf)는 기본적으로 저장 안 한다(`retain_grad()`로 예외).
- `torch.no_grad()`는 블록 전체 기록을 끄고, `.detach()`는 특정 Tensor만 분리한다.
- `backward()`는 parameter를 안 바꾸고 gradient만 계산한다. 바꾸는 건 `optimizer.step()`.
- `.backward()`는 `.grad`에 **더한다** → mini-batch마다 `zero_grad()`.
- `model.eval()`(Dropout·BatchNorm 동작 전환)과 `torch.no_grad()`(그래프 기록 중지)는 서로 대체할 수 없다.

## 왜 중요한가
- 학습이 안 될 때 `backward()`를 다시 부르는 게 아니라 그래프 연결 → `.grad` 상태 → 입력 scale → 학습/평가 모드 순서로 확인하는 기준이 생겼다.

## 코드/예시
```python
loss.backward()
for name, param in model.named_parameters():
    if param.grad is None:
        print(name, "graph disconnected")
    else:
        print(name, param.grad.shape, param.grad.norm().item())

model.eval()
with torch.no_grad():
    logits = model(x)
    pred = logits.argmax(dim=1)
model.train()

metric_pred = logits.detach().argmax(dim=1)   # detach는 metric·로그 경로에만
```

## 헷갈렸던 부분 & 해결
- `nn.Linear(2, 1).weight`가 왜 스칼라가 아니지? → 입력 feature가 2개라 출력 하나에도 weight 2개. shape `[1, 2]`, `y = w1*x1 + w2*x2 + b`.
- `param.grad is None` ≠ gradient 0. None은 그래프에 안 들어갔거나 끊긴 것, 0은 backward는 됐는데 값이 0인 것.
- gradient가 크다고 바로 clipping하지 말고 입력 scale부터 본다. MSE에서 입력을 10배 키우면 gradient norm이 약 100배.
- `.reshape(-1, 1)`은 `[N]`을 `[N, 1]`로, `zeros_like(x)`는 shape·dtype이 같은 0 Tensor.
