## 오늘 배운 것
- `Dataset`은 sample 하나를 어떻게 가져올지, `DataLoader`는 batch로 묶고 shuffle·반복을 맡는다. Tensor가 이미 있으면 `TensorDataset`, 파일 읽기·transform이 필요하면 `__len__`·`__getitem__`을 구현한 Custom Dataset.
- transform은 전체 전처리, augmentation은 그중 train을 다양하게 만드는 일부다. validation·test에는 무작위 augmentation을 안 쓴다.
- 정규화 평균·표준편차는 **train에서 한 번** 계산해서 모든 split에 적용한다. validation 자기 통계를 쓰면 평가 데이터 정보를 미리 쓰는 셈이다.
- split용 generator와 shuffle용 generator를 분리하면 "어떤 데이터가 어느 split인지"와 "epoch 순서"를 따로 재현할 수 있다.
- 학습 전에 첫 batch로 input·target의 shape·dtype·범위, device 일치, logits shape, scalar loss를 먼저 검사한다.
- 8장: `nn.Module → loss·optimizer → train → validation → metric → history`를 하나로 연결. 학습은 gradient·update, 검증은 `torch.no_grad()`.
- epoch Loss는 `loss.item() * y.shape[0]`로 batch 합계를 복원해서 **전체 sample 수**로 나눈다. 마지막 batch가 작을 수 있어서 batch 평균을 다시 평균 내면 안 된다.

## 왜 중요한가
- `random_split`의 Subset들은 같은 원본 Dataset을 공유해서, 원본 transform을 train용으로 바꾸면 validation에도 augmentation이 섞인다. split별 transform 격리는 **평가 무결성** 문제다.
- validation loss로 best epoch를 고르고 test는 마지막에 한 번만 본다(머신러닝 1장부터 이어지는 원칙).

## 코드/예시
```python
class SubsetWithTransform(Dataset):
    def __init__(self, base_dataset, indices, transform=None):
        self.base_dataset = base_dataset
        self.indices = list(indices)
        self.transform = transform

    def __len__(self):
        return len(self.indices)

    def __getitem__(self, idx):
        x, y = self.base_dataset[self.indices[idx]]
        if self.transform is not None:
            x = self.transform(x)
        return x, y

def run_epoch(training, loader):
    model.train(training)
    total_loss = seen = 0
    context = torch.enable_grad() if training else torch.no_grad()
    with context:
        for x, y in loader:
            if training:
                optimizer.zero_grad()
            loss = criterion(model(x), y)
            if training:
                loss.backward()
                optimizer.step()
            total_loss += loss.item() * y.shape[0]
            seen += y.shape[0]
    return total_loss / seen
```

## 헷갈렸던 부분 & 해결
- `total_loss = seen = 0`은 두 변수를 한 번에 0으로 만드는 다중 할당.
- `valid_unchanged &= condition`은 `valid_unchanged = valid_unchanged and condition`. 한 번이라도 parameter가 바뀌면 계속 False.
- `min(range(len(valid_loss)), key=valid_loss.__getitem__)`은 최솟값이 아니라 그 **index**를 준다. `[0.80, 0.62, 0.67]` → 두 번째 epoch.
- `x.shape`은 `torch.Size([4, 6])` 전체라 곱셈에 못 쓰고, batch 수는 `x.shape[0]`.
- `unbiased=False`는 `N`으로 나누는 표준편차, epsilon은 0으로 나누기 방지.
- 시간이 없어서 8-1~8-7 대신 종합 실습 8-8만 했다. 실행한 것과 각 단계를 설명할 수 있는 건 다르니 완료로 안 쳤다.
