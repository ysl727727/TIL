> 딥러닝 심화 3장 실습 · Attention과 Multi-Head Attention (3-1 ~ 3-5)

## 오늘 배운 것
- Q·K·V는 입력 `X`에 서로 다른 학습된 projection(`W_Q`, `W_K`, `W_V`)을 곱한 결과다. 모든 token에 같은 `W_q`가 적용된다.
- `d_k`와 `d_v`는 달라도 된다. Q·K는 내적해야 해서 차원이 같아야 하고, V는 가중합만 하니까.
- Softmax는 Key 축(`dim=-1`)에. 각 Query가 Key들에게 나눠 주는 관심의 합이 1이어야 한다.
- `√d_k`로 나누는 이유: 차원이 크면 내적이 커져 softmax가 한 곳에 쏠리고 gradient가 작아진다. head 분리 전엔 `hidden_size`, 후엔 `head_dim`.
- padding Key는 `masked_fill(~key_mask, -inf)` → `e^(-inf)=0`이라 나머지가 자동으로 재분배된다. 모든 Key가 mask되면 NaN이라 따로 오류 처리.
- context 기여도: `contributions = weights.unsqueeze(-1) * V` → `sum(dim=0)` = `weights @ V`와 같지만 누가 얼마나 기여했는지 볼 수 있다.
- attention entropy `-Σ p log p`: 골고루 퍼질수록 크고, 한 곳에 몰릴수록 작다.
- Multi-Head: 하나의 큰 `W_q`로 먼저 투영한 **다음** head 수만큼 나눈다. `[B,L,D] → [B,H,L,D_head] → [B,L,D]`.
- MHA(`H_q = H_kv`) · MQA(`H_kv = 1`) · GQA(`1 < H_kv < H_q`). KV Cache는 `H_kv`에 비례해서 `H_q=32, H_kv=8`이면 1/4.

## 왜 중요한가
- weight를 함수 밖 Tensor가 아니라 `nn.Linear`로 등록해야 optimizer가 찾아서 갱신한다.
- shape trace로 기대 shape와 처음 어긋나는 단계를 찾으면, 오류가 마지막 matmul에서 나도 진짜 원인(head 분리)을 찾을 수 있다.

## 코드/예시
```python
scores = (Q @ K.transpose(-2, -1)) / math.sqrt(Q.size(-1))
scores = scores.masked_fill(~key_mask.unsqueeze(1), float("-inf"))   # softmax 전에
weights = torch.softmax(scores, dim=-1)
output = weights @ V

def split_heads(x, num_heads):
    batch, length, d_model = x.shape
    d_head = d_model // num_heads
    return x.reshape(batch, length, num_heads, d_head).transpose(1, 2)

def merge_heads(x):
    batch, heads, length, d_head = x.shape
    return x.transpose(1, 2).contiguous().reshape(batch, length, heads * d_head)
```
- q/k/v/out `nn.Linear(6, 6, bias=False)` 4개 → parameter `4 × 6² = 144`

## 헷갈렸던 부분 & 해결
- `unsqueeze`가 값을 고르는 연산인 줄 알았는데 **차원을 추가**할 뿐이다. `key_mask.unsqueeze(1)`로 Query 축에 1을 넣어 모든 Query 행에 같은 mask를 broadcasting.
- Q-K 사전 검사는 **차원**(`Q.size(-1) == K.size(-1)`), K-V 검사는 **토큰 개수**(`K.size(-2) == V.size(-2)`). 서로 다른 걸 검증한다.
- `sum(dim=0)`은 "가로로 더하기"가 아니라 0번째 축을 없앨 때까지 세로로 합치기.
- `numel()`(원소 총 개수) vs `size(0)`(0번째 축 크기). `size(0)`의 0은 축 번호.
- `torch.matmul` = `@`. 3차원 이상이면 앞 batch 축은 두고 마지막 두 축끼리 곱한다.
- "K/V가 Q와 다를 수 있다"는 두 축이다: Self vs Cross는 **토큰 개수**, MHA vs GQA는 **head 개수**.
