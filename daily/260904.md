# 2026-09-04 TIL

> 딥러닝 심화 4강 · Transformer 전체 구조 (4-1 ~ 4-6 이론)

## 오늘 배운 것
- Self-Attention은 부품 하나, Transformer Block은 Attention + FFN + Residual + LayerNorm, Transformer Model은 Embedding + Block 여러 층 + Output Head.
- Encoder-only(BERT, 앞뒤 다 봄) · Decoder-only(GPT, 과거만) · Encoder-Decoder(T5, 번역·요약).
- 본체 출력은 hidden state `[B,L,D]`. **Head를 붙여야** logits(`[B,C]`, `[B,L,V]`), softmax까지 해야 확률.
- Self-Attention은 순서를 몰라서 위치 정보를 더한다(`[B,L,D] + [1,L,D]`). Learned / Sinusoidal, 최신은 RoPE.
- Causal mask는 `torch.triu(…, diagonal=1)`, True = 미래(차단). Label shift로 문장 하나에서 다음 토큰 문제 여러 개.
- FFN은 토큰 내부를 `D → D_ff → D`로 가공, Residual은 `X + Sublayer(X)`(변화량만 더함), LayerNorm은 한 토큰의 D축 안에서 정규화.
- 학습은 병렬(정답을 알고 있음), 생성은 순차. Prefill(프롬프트 한 번에) → Decode(한 토큰씩). KV Cache는 과거 K·V만 저장.

## 왜 중요한가
- 3강의 Attention을 전체 그림 안에 놓으니, 5강(BERT vs GPT), 9강(`generate()`·KV cache), RAG 1장(KV cache·CAG)이 한 줄로 이어졌다.
- Attention 칸 수가 `B × H × L × L`이라 L이 2배면 4배 → 긴 컨텍스트가 비싼 이유를 숫자로 이해했다.

## 코드/예시
```python
def make_causal_mask(L):
    return torch.triu(torch.ones(L, L, dtype=torch.bool), diagonal=1)

decoder_hidden = transformer(src=source_hidden, tgt=target_hidden,
                             tgt_mask=nn.Transformer.generate_square_subsequent_mask(4))  # [2,4,16]
logits = nn.Linear(16, 100)(decoder_hidden)                                               # [2,4,100]
```

```text
KV Cache bytes ≈ 2 × layers × batch × cached_length × kv_heads × D_head × bytes
```

## 헷갈렸던 부분 & 해결
- `diagonal=0`이면 자기 자신까지 막아 버린다 → `diagonal=1`.
- mask 규칙이 API마다 반대: Hugging Face `attention_mask`는 `1 = 사용`, PyTorch bool mask는 `True = 차단`.
- Residual은 "입력 복사"가 아니라 학습한 변화가 더해진 것. LayerNorm 출력도 학습되는 scale·bias 때문에 항상 평균 0·분산 1은 아니다.
- KV Cache는 반복 계산을 줄일 뿐 생성을 병렬로 만들지는 않는다.
- 4강은 실습 노트북 없이 정리 노트의 코드로만 shape을 확인했다.
