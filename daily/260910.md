> LLM 실전 1장 · Logit, Softmax, 손실 함수, Optimizer (1-1 ~ 2-2 이론)

## 오늘 배운 것
- logit은 마지막 선형층이 내는 클래스별 원시 점수다. 음수도 되고 합이 1이 아니다. `logits → softmax → probability → loss`.
- 큰 logits(`[1000, 1001, 1002]`)는 `exp()`가 `inf`가 되고 `inf/inf = nan`. Softmax는 같은 상수를 빼도 결과가 같아서, 행마다 최댓값을 빼는 **max trick**으로 overflow를 피한다.
- 배치 `[B, C]`는 클래스 축이 마지막이라 `axis=-1`, `keepdims=True`로 broadcasting을 안전하게. `axis=0`이면 실행은 되지만 틀린 값.
- 손실: 회귀 MSE `(1/N)Σ(ŷ−y)²`, 이진 BCE `−[y log p + (1−y) log(1−p)]`, 다중 CE `−log p(정답 클래스)`.
- `np.clip(p, eps, 1−eps)`는 `log(0)`을 막는 수치 처리일 뿐 틀린 예측을 고치는 게 아니다.
- Gradient는 loss가 **증가**하는 방향 → 반대로 간다: `θ ← θ − η∇L`. 선형 모델 MSE: `grad_w = 2·mean(errors·x)`, `grad_b = 2·mean(errors)`.
- SGD(현재 gradient만) · Momentum(velocity 누적, `v = βv + g`) · Adam(1차 `m` 방향 + 2차 `v` 크기, 편향 보정 `m_hat`·`v_hat`).

## 왜 중요한가
- 학습할 때 `CrossEntropyLoss`·`BCEWithLogitsLoss`에는 softmax 전 logits를 바로 넣는다(내부에서 안정적으로 계산). 딥러닝 기초 4장의 "출력층에 Softmax 넣지 않기"가 왜 그런지 수식으로 이해됐다.
- optimizer만 바꾸고 learning rate를 그대로 두면 공정한 비교가 아닐 수 있다. checkpoint에는 optimizer state(velocity, `m`, `v`)도 저장해야 정확히 이어서 학습한다.

def stable_softmax(x):
    shifted = x - x.max(axis=-1, keepdims=True)
    exp = np.exp(shifted)
    return exp / exp.sum(axis=-1, keepdims=True)

def stable_log_softmax(x):

## 헷갈렸던 부분 & 해결
- gradient 부호가 헷갈렸다 → "gradient가 양수면 그쪽으로 가면 loss가 커지니 반대로"로 기억.
- 클래스 인덱스와 one-hot은 같은 정보지만 API가 기대하는 형식이 다르다.
- reduction(`none`/`mean`/`sum`)은 표시뿐 아니라 gradient 크기에도 영향을 준다.
- 통합 실습 노트북(사내 LLM 출력 채점: 부서 분류 CE · 답변 품질 MSE · 민감정보 BCE)을 시작했지만 TODO 1~3이 `NotImplementedError` 상태로 남았다.
