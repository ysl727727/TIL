## 왜 중요한가
- `if __name__ == "__main__":` 밖의 코드는 **import될 때도 실행**된다. step 파일에 붙인 퀴즈가 practice08 실행 때 먼저 출력된 원인이었다 → 퀴즈는 별도 파일로.
- 성공과 실패를 같은 모양으로 반환하고, 형식 검사는 필드·타입만, 내용은 사람이 판단한다(모델이 "주문번호로만 조회 가능"처럼 프롬프트에 없는 단정을 했다).

## 코드/예시
```python
# max 없이 for문으로 후보 고르기 (> 이면 동점일 때 먼저 나온 것)
best = None
for c in candidates:
    if best is None or c["f1"] > best["f1"]:
        best = c

def find_correct_label(index, correct_labels, wrong_labels):
    label = correct_labels[index]
    for wrong_index, wrong_label in enumerate(wrong_labels):
        if wrong_label == label:
            return label, wrong_index
    raise ValueError(f"{label}이(가) wrong_labels에 없습니다.")
```

## 헷갈렸던 부분 & 해결
- lambda에 반복문이 들어 있나? → 아니다. 반복은 `max`/`min`/`sorted`가 하고, 원소마다 lambda를 한 번씩 부른다.
- `round([probs[index], 4])` → 리스트를 넘겨서 `TypeError`. `round(probs[index], 4)`.
- `for label in wrong_labels`로 같은 이름을 덮어써서 진짜 라벨이 사라졌다.
- 퀴즈 함수 이름 오타 `aplly_policy` 때문에 import한 step08의 `apply_policy`가 대신 불렸다(`KeyError: 'classification'`).
- `.env`는 step07이 만드는 게 아니라 직접 만든다(`Copy-Item .env.example .env`).
- `>>>` 채팅 안에서 친 `ollama stop`은 명령이 아니라 모델에게 보낸 질문이었다. 실행 중 모델은 `ollama ps`.
- `cls`·`text` 첫 칸은 파이썬이 자동으로 채우는 자리라 비워 둔다.
