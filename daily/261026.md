## 오늘 배운 것
- **검색됐다 ≠ 답할 수 있다.** `chunk_id`로 중복 제거 → `[S1] 제목\n본문` 조각 → 문자 예산(120·200·300) 안에 들어가는 근거만 Context. 조각 사이 `\n\n`도 예산이라 `+2`.
- 2-Step RAG: `prepare → invoke_model → finish`. JSON Schema(enum, `additionalProperties: False`)로 형식을 강제하고, Ollama 응답은 JSON 두 겹(`response.json()["message"]["content"]` → `json.loads`).
- `validate_answer`: S99 같은 가짜 출처 차단, answered면 출처 1개 이상, insufficient면 `citations: []`.
- Citation `bind_claim`: 출처 → 발췌 → URL. "1박당 → 출장 전체" 같은 의미 오류는 `review_meaning`까지만 표시하고 판단은 사람.
- 보류: 무엇이 부족한지 적고 `citations: []`. `insufficient ≠ system_error ≠ invalid_output`.
- BM25는 조사 하나로 결과가 바뀐다(영수증 vs 영수증을). 문서 길이를 평균과 비교해 보정한다는 점이 TF-IDF와 다르다. Dense는 상관없는 질문에도 Top-k를 낸다.
- RRF `1/(60 + rank)`로 점수 대신 **순위**를 합친다. Cross-Encoder는 (질문, 청크) 쌍을 다시 채점하지만 받은 후보 안에서만. Multi-Query로 q10 `[]` → education@60.
- Python 보강: `/`(항상 실수) · `//`(몫) · `%`(나머지), 누적 패턴, 중첩 반복, f-string 서식. q1~q5 통과.

## 헷갈렸던 부분 & 해결
- `pack_context(found, maxchars=budget)` → 키워드 이름이 한 글자라도 다르면 `TypeError`. `max_chars`.
- 중복 제거 4가지: ① `{row["chunk_id"]: row}`(나중 것) ② `setdefault`(처음 것) ③ `dict.fromkeys(queries)`(질문 중복) ④ 문서 다양성(같은 문서면 다 빼서 meal 0까지 빠짐).
- `extend` vs `append`: `[1, 2].extend([3, 4])` → `[1, 2, 3, 4]`, `append` → `[1, 2, [3, 4]]`.
- Cross-Encoder `activation_fn=torch.nn.Identity()` = 시그모이드 없이 logit 그대로 점수.
- Python: `range(1, n)`이면 n이 빠지고, 콜라츠에서 `n / 2`면 실수가 된다(`//`). 들여쓰기 = 언제 실행되느냐.
