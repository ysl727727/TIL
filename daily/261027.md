## 왜 중요한가
- RAGAS 결과가 교안과 조금 달랐고, 금액이 틀린 답변 B가 A보다 Relevancy가 높았다. 채점도 LLM이라 흔들리고, 지표 하나로 정확성을 판정하면 안 된다.
- 문서 Recall 1.0이어도 답(수료증·영수증)이 든 **청크**가 들어왔는지는 본문을 읽어야 안다.
- 오늘 교훈: 바꿨으면 숫자로 비교한다 / 작게 찾고 크게 답한다 / 반복에는 종료 조건 / 모델·그래프 결과는 원문으로 다시 검사.

## 헷갈렸던 부분 & 해결
- "k=3인데 왜 문서가 3개가 아니지?" → 같은 문서의 청크끼리는 문서 ID 집합에서 하나로 줄어든다.
- 9-2 `agent.py`에서 `KeyError: 'OLLAMA_MODEL'` → `os.environ["…"]`로 꺼내서 값이 없으면 바로 KeyError. 터미널마다 `$env:OLLAMA_MODEL="gemma3:4b-it-q4_K_M"`.
- 9-3 `DLL load failed while importing _epoch` → Windows 스마트 앱 컨트롤이 `srsly`의 `.pyd`를 막은 것(코드 오류 아님).
- 파라미터(만들 때 빈칸) vs 아규먼트(부를 때 넣는 값). argparse `store_true`는 붙이면 True.
- `tail`을 `items[-n:]`로 쓰면 n=0일 때 전체가 나온다 → `items[len(items) - n:]`.
- `sorted(counts, key=lambda s: s[0])`는 점수가 아니라 키의 첫 글자로 정렬한다 → 값 기준이면 `.items()` + `s[1]`.
- ColPali는 `transformers==5.5.2`에서 `KeyError: 'llava'` → `--with transformers==5.3.0`으로 로드.
