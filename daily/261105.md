```text
발제: Naive / Hybrid(BM25+RRF) / Hybrid+Reranker 3종 비교, FastAPI + LangChain + Langfuse, 문서명·페이지 표시, clarify / abstain
```

## 오늘 배운 것
- **페이지 단위로 먼저 나눈다.** 출처에 페이지 표시가 필수라서 페이지별로 읽어야 청크마다 `page`가 따라오고, 청크는 페이지 경계를 넘지 않게 자른다. 반복되는 꼬리말은 지우고 머리말은 `heading`으로 붙인다.
- **청킹은 근거 보존으로 고른다.** 정답 근거 인용 258개로 비교: 페이지 통째는 106쪽이 512토큰을 넘어 잘린 채 임베딩, 글자 500/overlap 100은 84.1%, **문단 800자는 98.1%**(최대 482토큰). 360쪽 → 청크 620개.
- **데이터 모양은 dataclass로 약속한다.** `PageDocument` → `Chunk` → `RetrievedChunk`. 순위 · 점수는 질문마다 달라서 `RetrievedChunk`가 `Chunk`를 품는다. `frozen=True`로 몰래 바뀌는 걸 막고 `asdict` / `Chunk(**payload)`로 Qdrant와 오간다.
- **Hybrid는 dense를 BM25로 바꾸는 게 아니라 같이 쓰는 것.** RRF `1/(60+순위)`로 순위를 합치고, Reranker는 후보를 cross-encoder로 다시 읽는다.
- **Qdrant Cloud.** 팀 공용 색인이라 처음부터 Cloud만. 무료 티어로 Advanced(약 28,000 청크)까지 충분하지만 1주일 안 쓰면 정지. 키는 클러스터마다, 만들 때 한 번만 보이니 바로 `.env`에.
- 내 결과(Naive, k=5): development Hit 0.929 · Recall 0.564 · Recall@20 0.867, additional Hit 0.929 · Recall 0.641. 하나는 거의 찾지만 근거 문서가 여럿인 질문은 절반을 놓친다.

## 왜 중요한가
- Recall@20이 0.87이라 정답 문서 대부분은 후보 20개 안에 있다. 순서만 잘 바꿔도(Reranker) 올라갈 여지가 크다 → 다음 작업의 근거.
- 검색만 따로 채점할 수 있으니 B · C를 기다리지 않고 기준점을 먼저 만들 수 있다. Hybrid / Reranker는 같은 반환 타입으로 붙이기만 하면 된다.
- 팀 공용 클러스터 · 공용 저장소라서, 남의 컬렉션을 덮어쓰지 않는 장치(`--recreate`)와 브랜치 · PR 규칙이 실제로 필요하다.

```python
# 같은 데이터가 단계마다 바뀌는 모양 (구조만 요약)
# PageDocument("SB02", "SB02.pdf", 5, text)          ← 페이지, 아직 chunk_id 없음

RetrievedChunk(chunk, rank, score, "dense")          # 청크는 그대로 품고, 질문마다 달라지는 값만 덧붙임

payload = asdict(chunk)       # Qdrant에 저장
chunk = Chunk(**payload)      # 다시 복원

# E5 규칙: 문서는 passage, 질문은 query
"passage: " + heading + text   # 색인할 때
"query: " + question           # 검색할 때
```

## 헷갈렸던 부분 & 해결
- **Qdrant Cloud `ConnectError [WinError 10054]`.** 다른 사이트 · DNS는 정상인데 `/healthz`도 안 열림 → 클러스터 문제로 판단, 미국 서부 리전에 새로 만들고 새 키로 교체.
- **`upload_points` 직후 개수가 틀림.** 기본이 `wait=False`라 업로드 완료를 안 기다린다 → `wait=True`.
- **정답은 "한 번만" 쓰나?** 아니라 "채점에만" 쓴다. 질문 파일로 검색을 다 돌린 뒤에 정답 파일을 연다.
- **dense = E5.** "E5가 코드에 약하다" = 지금 dense 검색이 약하다 → BM25를 추가.
- **`glob("*.pdf")`가 파일을 만드나?** 아니다. 경로 목록을 메모리에 만들 뿐, PDF는 미리 폴더에 넣어 둬야 한다.
- **clone vs branch.** 둘 중 하나가 아니라 clone으로 받고 그 안에서 branch. 브랜치 이름은 사람(`core/ysl`)이 아니라 작업(`feat/...`).
- Windows 콘솔 한글 깨짐 → `sys.stdout.reconfigure(encoding="utf-8")`. `get_sentence_embedding_dimension()` → `get_embedding_dimension()`.
