# 2026-11-18 TIL

> 파인튜닝 3일차 · 3장 전체 가중치 SFT와 학습 재개 (3-1 \~ 3-4)

## 큰 흐름
```text
3장:  손실 마스크(3-1) → 전체 SFT(3-2) → 곡선 읽기(3-3) → 재개 · 저장(3-4)
      370 = 299(−100) + 71 → 4.94억 개 · 24갱신 계획 · 12에서 멈춤 → 손실 ≠ 업무 정답 → 12 → 24 · sft_model
과정: 1 기준 → 2 데이터 72개 → 3 SFT → 4 LoRA → 5 QLoRA → 6 DPO → 7 평가 · API → 8 검증 · 인계
원칙: 답변 토큰만 채점해서 가중치를 바꾸고, 손실이 내려가도 업무 답은 따로 읽고, 이어서 학습할 상태와 쓸 모델은 나눠 저장한다.
```

## 오늘 배운 것
- **처음으로 가중치를 바꿨다.** 1 · 2장은 준비 단계, 3장은 Qwen2.5-0.5B의 494,032,768개 전부가 학습 대상(100%).
- **답변 토큰만 채점한다.** `encode_example`이 두 번 토큰화로 경계(299)를 찾고, EOS까지 자르고 뒤 `\n`만 버린 뒤 labels = −100 × 299 + 답변 · EOS 71.
- **배치는 패딩 세 값으로.** input은 pad ID, attention은 0(읽지 마), labels는 −100(채점하지 마) → (2, 379). Qwen은 pad ID가 종료 ID와 같아서 위치로 구분.
- **shift는 한 곳에서 한 번.** t번째 출력이 t+1번째를 맞힌다(`logits[:, :-1]` ↔ `labels[:, 1:]`). 3 \~ 5장은 모델 내부, 6장 DPO만 직접.
- **TrainingArguments는 설정표.** 배치 1 × 누적 4 = 유효 배치 4, 48 ÷ 4 = 12갱신 = 1 epoch, 24갱신 = 2 epoch. `StopAtTwelve`는 계획(24)은 두고 멈추기만.
- **손실 ≠ 업무 정답.** 손실은 토큰 평균이라 "이하/초과" 몇 토큰의 실수가 묻힌다. 슬라이드는 dev loss 0.0049인데 over\_limit 2문항이 틀렸다.
- **체크포인트 ≠ 추론용 모델.** 재개엔 optimizer · scheduler · 난수 · step까지, `sft_model`엔 가중치 · 설정 · 토크나이저만. `resume_from_checkpoint`로 12 → 24.

## 왜 중요한가
- 마스킹 · 패딩 · shift 중 하나만 틀려도 학습은 에러 없이 돌고 엉뚱한 걸 배운다. 3장은 "무엇을 맞히게 하는지"를 코드로 확인하는 단계.
- 손실 곡선만 보고 "좋아졌다"고 하면 업무상 오답을 놓친다. 7장에서 생성 답을 규칙으로 채점하는 이유.
- 긴 학습은 중간에 끊긴다(Colab 종료 · GPU 선점). 같은 계획으로 이어 갈 수 있게 저장해야 한다.

## 헷갈렸던 부분 & 해결
- **`[:, :-1, :]`과 `[:, 1:]`.** 쉼표는 축 구분, 위치 축만 자른다. logits는 마지막을 빼고 labels는 첫 칸을 뺀다(처음엔 반대로 헷갈림).
- **슬라이싱 · −100 · attention 0.** 슬라이싱은 아예 없앰, −100은 읽지만 채점 X, attention 0은 읽지도 않음.
- **`eval_steps=4`는 accumulation 때문?** 반만 맞음. step은 갱신 횟수라 4갱신 × 4문항 = 16문항마다.
- **gradient checkpointing ≠ 학습 체크포인트.** 앞은 메모리 아끼는 계산 방식, 뒤는 디스크에 저장하는 폴더.
- **`reset_peak_memory_stats()`.** 메모리를 비우는 게 아니라 최고값 기록을 0으로 되돌리는 것. 비우는 건 `del` + `gc.collect()` + `empty_cache()`.
- **내 실행(T4 · FP32) vs 슬라이드(BF16).** 표본 변화 256/256 vs 24/256(BF16은 작은 변화가 반올림으로 사라짐), 최종 dev loss 0.0003 vs 0.0049, 관찰 문항 맞음 vs 틀림. dev 1문항만 본 거라 일반화 X, 시간은 T4가 훨씬 느림(약 11분 vs 27초).
