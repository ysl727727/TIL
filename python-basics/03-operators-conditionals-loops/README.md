## 오늘 배운 것

### 1. 연산자

| 연산 | 뜻 | 예 |
| --- | --- | --- |
| `/` | 나누기, **항상 실수** | `16 / 2 → 8.0`, `10 / 3 → 3.3333333333333335` |
| `//` | 몫 (내림) | `7 // 2 → 3`, `-7 // 2 → -4` |
| `%` | 나머지 | `n % 2 == 0` 짝수 판별, `1234 % 10 → 4` 마지막 자리 |
| `**` | 거듭제곱 | `2 ** 10 → 1024` |

- 정수끼리 나눠서 정수가 필요하면 `//` (자릿수, 진법, 콜라츠). 실수는 정밀도 한계가 있음
- 수학처럼 곱하기 생략 불가: `2i` ❌ → `2 * i`, `2(h - i)` ❌ → `2 * (h - i)`

### 2. 조건문

- 위에서부터 **첫 번째로 맞는 길 하나만** 실행 → 조건 순서가 결과를 바꿈
- 경계값(90, 80, 70)을 꼭 테스트

### 3. 누적 패턴 (세 줄)

| 구하는 것 | 초기값 | 쌓는 줄 |
| --- | --- | --- |
| 합 | `total = 0` | `total += n` |
| 개수 | `count = 0` | `if 조건: count += 1` |
| 최대 | `largest = numbers[0]` | `if n > largest: largest = n` |

- 최대값의 **처음** 위치를 원하면 `>=`가 아니라 `>` (같은 값이면 안 바꿈)
- 몇 번 돌지 모르면 `while` → 안에서 조건을 거짓으로 만드는 줄이 꼭 있어야 함

### 4. 중첩 반복 순서

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()   # 안쪽 for가 끝날 때마다 줄바꿈
```

- 바깥 `i` 한 번에 안쪽 `j`가 끝까지 다 돎 (시침/분침) → 총 3 × 3 = 9번
- 순서 없이 서로 다른 두 수 고르기: 안쪽을 `range(i + 1, n + 1)`로 시작 → 중복·같은 수 제외

### 6. 내장 함수

| 함수 | 결과 | 뜻 |
| --- | --- | --- |
| `bin(13)` / `bin(13)[2:]` | `'0b1101'` / `'1101'` | 2진수 문자열 (`[2:]`로 `0b` 제거) |
| `int("1101", 2)` | `13` | 2진수 문자열 → 정수 |
| `hex(255)` | `'0xff'` | 16진수 문자열 |
| `math.gcd(48, 18)` | `6` | 최대공약수 (`import math` 필요) |
| `divmod(17, 5)` | `(3, 2)` | `(17 // 5, 17 % 5)`, `q, r = divmod(...)`로 받기 |

### 7. f-string 서식 `{값:서식}`

| 서식 | 결과 | 뜻 |
| --- | --- | --- |
| `{3.14159:.2f}` | `3.14` | 소수 둘째 자리 |
| `{42:5d}` | `   42` | 5칸 (숫자는 기본 오른쪽 정렬) |
| `{42:05d}` | `00042` | 5칸, 0 채움 |
| `{0.256:.1%}` | `25.6%` | ×100 후 % (비율 0~1일 때만) |
| `{'A':>3}` / `<3` / `^3` | `'  A'` / `'A  '` / `' A '` | 오른쪽 / 왼쪽 / 가운데 정렬 |
| `{'A':^4}` | `' A  '` | 가운데에서 남는 칸이 홀수면 **오른쪽**에 하나 더 |

같은 날 RAG 실습에서도 f-string을 만났어요: `{budget, results[...]}`처럼 중괄호 안에 쉼표로 두 값을 넣으면 **튜플 하나**로 묶여 `(300, ['meal'])`로 찍혀요 → [RAG 6장](../../rag/06-context-2step-rag-citation/#f-string-중괄호-안의-쉼표는-튜플)

## 내가 한 실수

| 실수 | 증상 | 고침 |
| --- | --- | --- |
| `range(1, n)` | 마지막 수 n이 빠짐 (5050 → 4950) | `range(1, n + 1)` |
| `count += i` | 개수가 아니라 합이 됨 | `count += 1` |
| `return`을 for 안(8칸)에 | 첫 바퀴에서 함수 종료 | for와 같은 4칸으로 (`Shift+Tab`) |
| `steps = n + 1`을 while 밖에 | 매 바퀴 세지 않고 끝에 한 번만 계산 | while 안에 `steps += 1` |
| 콜라츠에서 `n / 2` | `8.0`처럼 실수로 바뀜 | `n // 2` |
| 반복 변수를 매개변수와 같은 `n`으로 | 매개변수를 덮어써서 헷갈림 | `i`처럼 다른 이름 |
| 함수 이름과 같은 변수 이름 (`grade`, `sum_to`) | 동작은 하지만 헷갈림 | `result`, `total` 등 |
