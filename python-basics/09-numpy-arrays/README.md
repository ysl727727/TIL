## 2. 왜 배열인가: 반복문 없이 한 번에

```python
scores = [70, 85, 90, 60, 75]
bonus = []
for s in scores:
    bonus.append(s + 10)
print(bonus)                     # [80, 95, 100, 70, 85]
print(scores * 2)                # [70, 85, 90, 60, 75, 70, 85, 90, 60, 75]  곱하기가 아니라 이어 붙이기!
```

```python
arr = np.array(scores)           # 리스트 → 배열
print(arr + 10)                  # [ 80  95 100  70  85]
print(arr * 2)                   # [140 170 180 120 150]
print(arr.dtype)                 # int64   원소의 타입
print(np.array([1, 2.5]).dtype)  # float64 하나라도 실수면 전부 실수
```

- **벡터화**: 식을 한 번만 쓰면 모든 원소에 적용.
- 리스트 = 상자 여러 개(하나씩 열어서 바꿈), 배열 = 계란판(판 전체에 도장 한 번).
- 그래서 배열은 **같은 타입(dtype)만** 담는다. 대신 코드는 수식처럼 짧고, 반복문보다 수십 배 빠르다.
- 실수: 리스트에 `scores + 10` → TypeError, `scores * 2` → 이어 붙이기. **계산 전에 `np.array(...)`로 바꿨는지 확인.**

## 3. shape: 배열의 모양 읽기

```python
a = np.array([3, 1, 4, 1])
m = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.shape, a.ndim)           # (4,) 1     1차원, 원소 4개
print(m.shape, m.ndim)           # (2, 3) 2   2차원, 행 2개 열 3개
print(len(m))                    # 2          len은 첫 번째 축의 길이
print(np.arange(6))              # [0 1 2 3 4 5]
print(np.arange(6).reshape(2, 3))
# [[0 1 2]
#  [3 4 5]]
print(np.zeros(3), np.ones((2, 2)).shape, np.linspace(0, 1, 5))
# [0. 0. 0.] (2, 2) [0.   0.25 0.5  0.75 1.  ]
```

```
m.shape == (2, 3)

         열 0  열 1  열 2
  행 0 [   1,    2,    3 ]
  행 1 [   4,    5,    6 ]
```

- shape = 축마다의 길이를 담은 튜플. `(4,)`처럼 쉼표 있는 건 원소 하나짜리 튜플.
- `reshape`는 원소 수가 같아야 한다. 6개를 (4, 2)로 → 오류.
- **코드가 이상하면 먼저 `print(x.shape)`.** 가장 많이 쓰는 디버깅.

### Q. ones, linspace 뜻?

| 함수 | 뜻 | 예 |
|---|---|---|
| `np.zeros(모양)` | 0으로 채운 배열 | `np.zeros(3)` → `[0. 0. 0.]` |
| `np.ones(모양)` | 1로 채운 배열 | `np.ones((2, 2))` → `[[1. 1.] [1. 1.]]`, shape `(2, 2)` |
| `np.linspace(시작, 끝, 개수)` | 끝 **포함**, 같은 간격으로 개수만큼 | `np.linspace(0, 1, 5)` → `[0. 0.25 0.5 0.75 1.]` |
| `np.arange(끝)` | 간격 1, 끝 **미포함** | `np.arange(6)` → `[0 1 2 3 4 5]` |

- 2차원 이상은 모양을 **튜플**로: `ones((2, 2))` (괄호 두 겹).
- linspace 간격 = (끝 - 시작) ÷ (개수 - 1) = 1 ÷ 4 = 0.25. 숫자 5개 사이엔 칸이 4개.
- `arange`는 **간격**을 정하고, `linspace`는 **개수**를 정한다.
- `0.`, `1.`처럼 점이 붙으면 실수(float).

## 4. axis: 어느 방향으로 접을까

```python
scores = np.array([[80, 90,  70],    # 영희: 국어, 영어, 수학
                   [60, 70, 100],    # 철수
                   [90, 80,  85],    # 민지
                   [70, 60,  75]])   # 동현
print(scores.shape)                  # (4, 3)
print(scores.sum())                  # 930  전부 더하기
print(scores.mean(axis=0))           # [75.  75.  82.5]  과목마다 평균
print(scores.mean(axis=1).round(1))  # [80.  76.7 85.  68.3]  학생마다 평균
print(scores.max(axis=0))            # [ 90  90 100]  과목마다 최고점
print(scores.argmax(axis=0))         # [2 0 1]  최고점을 받은 학생의 위치
```

```
axis=0: 위아래로 접어요              axis=1: 옆으로 접어요
(행이 없어져요)                      (열이 없어져요)

[[80, 90,  70],                      [[80, 90,  70],  → 80.0
 [60, 70, 100],                       [60, 70, 100],  → 76.7
 [90, 80,  85],                       [90, 80,  85],  → 85.0
 [70, 60,  75]]                       [70, 60,  75]]  → 68.3
  ↓   ↓    ↓
[75, 75, 82.5]

(4, 3) → (3,)                        (4, 3) → (4,)
```

- `axis=k` = **k번 축을 없애면서 계산**.
- 헷갈리면 **결과 모양부터**: 과목마다 하나 남아야 하면 `(3,)` → 길이 4인 0번 축을 없애야 → `axis=0`.
- `argmax`는 가장 큰 값의 **위치**, `max`는 **값**.

### 외울 것
- 열마다(과목마다) → `axis=0` → 결과 `(열 수,)`
- 행마다(학생마다) → `axis=1` → 결과 `(행 수,)`

## 5. 인덱싱과 마스크: 원하는 부분만 꺼내기

```python
a = np.array([3, -1, 7, 0, 5])
print(a[0], a[-1], a[1:3])          # 3 5 [-1  7]
print(scores[1, 2])                 # 100  철수의 수학 [행, 열]
print(scores[0], scores[:, 2])      # [80 90 70] [ 70 100  85  75]  영희의 행, 수학 열
mask = a > 2
print(mask)                         # [ True False  True False  True]
print(a[mask], mask.sum())          # [3 7 5] 3
print(a[(a > 0) & (a < 6)])         # [3 5]  두 조건을 모두
print(np.where(a < 0, 0, a))        # [3 0 7 0 5]  조건이 참이면 0, 거짓이면 원래 값
```

- 2차원은 `[행, 열]`. `:`는 "전부" → `scores[:, 2]` = 모든 행의 2번 열.
- 불리언 마스크 = True/False 배열. `a[mask]`는 True인 자리만 꺼낸다.
- True=1, False=0으로 더해지니 **`mask.sum()` = 조건을 만족하는 개수**.
- 마스크로 행도 고른다: `scores[scores[:, 2] >= 80]` = 수학 80점 이상인 학생의 행.
- 실수: 두 조건을 `and`로 이으면 ValueError → **`&`** + **조건마다 괄호**. `a > 0 & a < 6`처럼 괄호 빼면 `&`가 먼저 계산돼서 오류.

### Q. `np.where(a < 0, 0, a)` 해석

`np.where(조건, 참일 때 값, 거짓일 때 값)` → 칸마다 조건 보고 골라 넣기.

| a | a < 0 | 결과 |
|---|---|---|
| 3 | False | 3 (원래 값) |
| -1 | **True** | **0** |
| 7 | False | 7 |
| 0 | False | 0 (0은 음수 아님) |
| 5 | False | 5 |

→ `[3 0 7 0 5]` = "음수만 0으로, 나머지 그대로"

- `a[조건]` = **고르기** (길이 줄어듦) → `[3 7 5]`
- `np.where(조건, A, B)` = **바꾸기** (모양 그대로) → `[3 0 7 0 5]`

## 6. 브로드캐스팅: 모양이 달라도 계산되는 규칙

### 출발점
`arr + 10`에서 10이 모든 칸에 더해진 것 = NumPy가 10을 배열 모양만큼 **늘려서(복사해서)** 계산한 것. 이게 브로드캐스팅. 배열끼리도 된다.

```python
m = np.array([[1., 2., 3.],
              [4., 5., 6.]])               # (2, 3)
print(m + np.array([100, 200, 300]))       # (2, 3) + (3,): 행마다 같은 줄을 더해요
# [[101. 202. 303.]
#  [104. 205. 306.]]
print(m + np.array([[10], [20]]))          # (2, 3) + (2, 1): 열마다 같은 칸을 더해요
# [[11. 12. 13.]
#  [24. 25. 26.]]
```

```
(2, 3) + (3,)                        (2, 3) + (2, 1)

[[1, 2, 3],   [[100, 200, 300],      [[1, 2, 3],   [[10, 10, 10],
 [4, 5, 6]] +  [100, 200, 300]]       [4, 5, 6]] +  [20, 20, 20]]
               ↑ 아래로 복사                         ↑ 옆으로 복사
```

- `(3,)` = 가로 한 줄 → **아래로** 복사 → 행마다 같은 값
- `(2, 1)` = 세로 한 줄 → **옆으로** 복사 → 열마다 같은 값

### 규칙: "뒤에서부터 축을 맞추고, 길이가 같거나 1이면 된다. 1이거나 없는 축은 복사해서 늘린다."

1. **뒤에서부터 축을 맞추고** → 두 모양을 **오른쪽 끝에 맞춰** 세운다.
   ```
   (2, 3)     2   3
   (3,)           3      ← 오른쪽 끝에 붙임. 앞자리는 비어 있음
   ```
2. **같거나 1이면 된다** → 세로줄마다 **같다 / 1이다 / 비어 있다** 중 하나면 통과. 하나라도 못 하면 오류.
3. **1이거나 없는 축은 복사해서 늘린다** → 결과 모양 = 각 줄의 **큰 숫자**.

| 왼쪽 | 오른쪽 | 뒤에서부터 비교 | 결과 |
|---|---|---|---|
| (2, 3) | (3,) | 3=3 / 2와 없음 → 늘림 | (2, 3) |
| (2, 3) | (2, 1) | 3과 1 → 늘림 / 2=2 | (2, 3) |
| (3, 1) | (1, 4) | 1→4 / 3과 1 → 늘림 (양쪽 다 늘어남) | (3, 4) |
| (2, 3) | (2,) | **3과 2: 같지도 않고 1도 아님** | **오류** |

### 가장 자주 하는 실수: 마지막 줄

```python
m - m.mean(axis=1)                           # (2, 3) - (2,) → 오류!
print(m.mean(axis=1).shape)                  # (2,)
row_mean = m.mean(axis=1, keepdims=True)     # (2, 1)  없앤 축을 길이 1로 남김
print(m - row_mean)
# [[-1.  0.  1.]
#  [-1.  0.  1.]]
```

- **`keepdims=True`** = axis로 없앤 축을 지우지 않고 길이 1로 남긴다 → `(2, 1)` → 옆으로 복사 가능.

### 활용: 한 점과 여러 점 사이의 거리

```python
points = np.array([[0, 0], [3, 4], [6, 8]])
q = np.array([3, 0])
diff = points - q                            # (3, 2) - (2,): 점마다 q를 빼요
print(diff.tolist())                         # [[-3, 0], [0, 4], [3, 8]]
dist = np.sqrt((diff ** 2).sum(axis=1))      # 피타고라스: 가로² + 세로²의 제곱근
print(dist.round(2))                         # [3.   4.   8.54]
print(dist.argmin())                         # 0  가장 가까운 점의 위치
```

### 외울 것
- 브로드캐스팅 = 작은 쪽을 **복사해서 늘려** 모양 맞추기
- **뒤에서부터** 비교, **같거나 1(또는 없음)**이면 OK
- 행마다 빼기/나누기 = `m 연산 m.함수(axis=1, keepdims=True)`

## 7. 평균·분산·표준편차: 데이터를 숫자 몇 개로 요약

- **평균** = 가운데가 어디인가
- **표준편차** = 평균에서 보통 얼마나 떨어져 있나

| x | 2 | 4 | 4 | 4 | 5 | 5 | 7 | 9 |
|---|---|---|---|---|---|---|---|---|
| 편차 x - 5 | -3 | -1 | -1 | -1 | 0 | 0 | 2 | 4 |
| 편차² | 9 | 1 | 1 | 1 | 0 | 0 | 4 | 16 |

- 평균 = 40 ÷ 8 = **5**
- 편차²의 합 32 → ÷ 8 = **4 (분산)**
- √4 = **2 (표준편차)**
- 편차를 그냥 더하면 +와 -가 지워져 항상 0 → 그래서 **제곱해서** 더한다.

```python
x = np.array([2, 4, 4, 4, 5, 5, 7, 9], dtype=float)
mean = x.sum() / len(x)
dev = x - mean                       # 편차: 브로드캐스팅으로 모든 원소에서 평균을 빼요
print(dev.sum())                     # 0.0  편차의 합은 항상 0
var = (dev ** 2).sum() / len(x)
std = var ** 0.5
print(mean, var, std)                # 5.0 4.0 2.0
print(x.mean(), x.var(), x.std())    # 5.0 4.0 2.0  NumPy 함수와 같아요
print((x - mean) / std)              # [-1.5 -0.5 -0.5 -0.5  0.   0.   1.   2. ]
```

- 마지막 줄 = **표준화**: "평균에서 표준편차 몇 개만큼 떨어져 있나". 9는 표준편차 2개만큼 위. 단위가 다른 데이터(키와 몸무게)를 같은 눈금으로 비교할 때.

### Q. 왜 `(dev ** 2).sum()`이야? (`(a - dev) ** 2` 아님)
- `dev`에는 이미 `a - 평균`이 들어 있다 → 다시 빼지 않는다.
- 순서: ① `dev = a - mean` → ② `dev ** 2` 칸마다 제곱 → ③ `.sum()` 다 더하기(32) → ④ `/ len(a)` 개수로 나누기(4.0)
- ③+④ = 평균 → 분산 = **편차²의 평균** = `(dev ** 2).mean()`과 같다.

### 평균이 같아도 퍼진 정도는 다르다 (그림)

```python
class_a = np.array([60, 65, 70, 75, 80])
class_b = np.array([40, 55, 70, 85, 100])
print(class_a.mean(), class_b.mean())                  # 70.0 70.0
print(class_a.std().round(1), class_b.std().round(1))  # 7.1 21.2
```

- 그림: 두 반 평균(점선)은 같지만 B반 점들이 훨씬 넓게 퍼져 있고, 평균 ± 표준편차 막대도 B반이 세 배쯤 길다.

### 외울 것
- 평균 → 편차(`x - 평균`) → 편차² → 평균 = **분산** → 제곱근 = **표준편차**
- 분산 = `((x - x.mean()) ** 2).mean()`
- 표준화 = `(x - x.mean()) / x.std()`

## 8. softmax: 점수를 확률로 바꾸기

모델이 고양이·개·새에 점수 `[2.0, 1.0, 0.1]` → "0 이상, 합이 1"인 확률로 바꾸고 싶다.
- 그냥 합으로 나누면? 음수 점수 `[2.0, -1.0, 0.1]`이면 음수 확률이 나온다.
- 그래서 먼저 **exp**(e ≈ 2.718의 지수)를 씌운다 → 항상 양수, 큰 점수는 여전히 크다 → 그다음 합으로 나눈다.

| | 고양이 | 개 | 새 | 합 |
|---|---|---|---|---|
| 점수 z | 2.0 | 1.0 | 0.1 | |
| exp(z) | 7.389 | 2.718 | 1.105 | 11.213 |
| 확률 | 0.659 | 0.242 | 0.099 | 1 |

```python
z = np.array([2.0, 1.0, 0.1])
e = np.exp(z)
p = e / e.sum()
print(e.round(3), p.round(3))    # [7.389 2.718 1.105] [0.659 0.242 0.099]
print(p.sum().round(6))          # 1.0
```

### 큰 수 문제: 오버플로

```python
big = np.array([1000.0, 1001.0, 1002.0])
print(np.exp(big))                  # [inf inf inf]  (경고도 함께 나와요)
print(big - big.max())              # [-2. -1.  0.]
e = np.exp(big - big.max())
print((e / e.sum()).round(3))       # [0.09  0.245 0.665]
```

- exp(1000) → 무한대(inf) → inf / inf = nan. 이게 **오버플로**.
- **가장 큰 값을 먼저 빼도 결과가 같다**: `exp(z - c) = exp(z) ÷ exp(c)` → 분자·분모가 똑같이 exp(c)로 나뉘어 지워진다.
- 빼고 나면 가장 큰 값이 0 → exp가 1 이하로 안전. 실제 라이브러리도 모두 이렇게.

### temperature (온도)

점수를 T로 나눈 뒤 softmax → 확률이 몰리거나 퍼진다.
- T 작음(0.5) → 고양이에 0.86까지 **몰림**
- T 큼(2.0) → 막대 높이 차이 **줄어듦**
- 순서(고양이 > 개 > 새)는 그대로.
- **LLM 설정의 temperature가 바로 이 T.** 낮으면 늘 비슷한 답, 높으면 다양한 답.

### 외울 것
- softmax = `exp(z - z.max())` ÷ 그 합
- 최댓값 빼기 = 오버플로(inf → nan) 방지, 결과는 같다
- 결과: 전부 0보다 크고 합 1

## 9. 실무 코드: 재현 가능한 가짜 데이터

```python
rng = np.random.default_rng(seed=0)
print(rng.integers(1, 7, size=5))            # [6 4 4 2 2]  1 이상 7 미만 정수 (주사위)
data = rng.normal(70, 10, size=(1000, 3))    # 평균 70, 표준편차 10 근처인 실수 1000행 × 3열
print(data.shape)                            # (1000, 3)
print(np.mean(data, axis=0).round(1))        # 열마다 평균: 70 근처
print(np.std(data, axis=0).round(1))         # 열마다 표준편차: 10 근처
```

- **seed가 같으면 매번 같은 난수** → 테스트 가능.
- `rng.normal(평균, 표준편차, size=모양)` = 종 모양으로 퍼진 실수.
- `np.mean(x, axis=0)` == `x.mean(axis=0)`.
- 표본 표준편차(n - 1로 나눔)는 `np.std(x, ddof=1)`. 오늘은 n으로 나누는 기본값.
- 옛 코드의 `np.random.seed(0)` 대신 `default_rng` → 난수 상태가 rng 객체 안에 있어서 섞이지 않는다.
- 히스토그램: 70 근처에 가장 많이 몰리는 종 모양, 빨간 선(평균)이 산 가운데.

## 10. 실습 답 (내가 푼 것)

### 기초 1. 화씨 → 섭씨

```python
def to_celsius(f):
    f = np.array(f)              # 리스트가 와도 배열로
    return (f - 32) * 5 / 9      # 공식 한 번 = 모든 칸 (벡터화)
```

- 실수: `np.array`만 쓰고 괄호·담기·return 없음 → None 반환 → AssertionError
- 배열로 바꾸기는 **`f = np.array(f)`처럼 호출하고 다시 담기.** return 없으면 None.

### 기초 2. 과목별 평균

```python
def subject_means(scores):
    scores = np.array(scores)
    return scores.mean(axis=0)
```

- 과목마다 하나 → 결과 `(3,)` → 학생 축(0번)을 없앰 → `axis=0`.

### 기초 3. 조건으로 세기

```python
def count_above(a, t):
    a = np.array(a)
    return int((a > t).sum())
```

- 실수: `len(a > t).sum()` → `len`은 True/False 상관없이 **칸 수 전체**(6) → 숫자에 `.sum()` 없음 → AttributeError
- 개수 = **`(조건).sum()`** (True=1). `int(...)`는 문제에서 int를 요구해서.

### 응용 1. 표준편차 직접

```python
def std_dev(a):
    a = np.array(a)
    mean = a.mean()
    dev = a - mean
    var = (dev ** 2).sum() / len(a)
    return np.sqrt(var)
```

- 실수: `var = np.mean(a) / len(a)` → 평균 ÷ 개수(5 ÷ 8 = 0.625), 편차를 안 구함.
- 분산은 "평균에서 얼마나 떨어져 있나" → **편차부터.**
- 금지: `np.std`, `np.var`, `.std()`, `.var()`. `np.sqrt`, `.mean()`, `.sum()`은 OK.

### 응용 2. 행 정규화

```python
def normalize_rows(m):
    m = np.array(m)
    return m / m.sum(axis=1, keepdims=True)
```

```
행 합 → [[ 4],        [[1, 1, 2],       [[0.25, 0.25, 0.5],
         [10]]  (2,1)  [0, 5, 5]] ÷ → [0.  , 0.5 , 0.5]]   ← 옆으로 복사
```

- `keepdims=True` 없으면 `(2, 3) / (2,)` → 뒤에서 3과 2 달라서 오류.

### 응용 3. softmax

```python
def softmax(z):
    z = np.array(z)
    e = np.exp(z - z.max())        # 최댓값 빼서 오버플로 방지
    return e / e.sum()             # 합으로 나눠 확률로
```

- `[1000, 1000, 1000]` → 빼면 `[0, 0, 0]` → exp `[1, 1, 1]` → `[1/3, 1/3, 1/3]`
- `[1, 2, 3]`과 `[101, 102, 103]` → 둘 다 빼면 `[-2, -1, 0]` → 결과 같다.

## 11. 오늘 질문 / 겪은 것

### Q. `np.asarray`가 뭐지?
받은 걸 배열로 바꾸는 함수. `np.array`와 거의 같다.

| | 리스트가 오면 | 이미 배열이면 |
|---|---|---|
| `np.array(x)` | 배열로 | **새로 복사** |
| `np.asarray(x)` | 배열로 | **그대로 씀** |

함수 첫 줄에서 "리스트가 와도 배열로" 용도. 이 문제들에선 어느 쪽을 써도 통과.

### Q. numpy 설치 명령어?
```powershell
uv add numpy matplotlib          # Notion 명령
uv add numpy==2.3.5 matplotlib   # 이 컴퓨터용 (버전 고정)
uv run python -c "import numpy as np; print(np.__version__)"   # 확인
```
- 최신 numpy 2.5.5는 Windows **스마트 앱 컨트롤**이 차단했다:
  `ImportError: DLL load failed ... 애플리케이션 제어 정책에서 이 파일을 차단했습니다.`
- 아직 평판이 안 쌓인 새 파일을 막는 기능 → 이미 널리 쓰인 **2.3.5로 고정**해서 해결.
- 다른 패키지도 같은 에러면 버전을 조금 낮추기.
- 실행은 `uv run python`으로 (그냥 `python`이면 `No module named 'numpy'` 가능).

## 12. 체크아웃

- axis=0은 **0번(행)** 축을 없애서 **열(과목)**마다 하나씩 남는다.
- softmax는 점수를 **확률**로 바꾸고, 큰 수에서는 먼저 **최댓값**을 뺀다.
- 기초 3문제 중 통과: **3** (응용 3문제도 통과)
- 다음 회차: 내적으로 문장 유사도 재는 **코사인 유사도**, 행렬 곱 **`@`**.

## 13. 오늘의 함수 치트시트

| 하고 싶은 것 | 코드 |
|---|---|
| 리스트 → 배열 | `np.array(x)` / `np.asarray(x)` |
| 타입 / 모양 / 차원 | `x.dtype` / `x.shape` / `x.ndim` |
| 0~n-1 / 0채움 / 1채움 / 등간격 | `np.arange(n)` / `np.zeros(모양)` / `np.ones(모양)` / `np.linspace(a, b, n)` |
| 모양 바꾸기 | `x.reshape(2, 3)` |
| 합·평균·최대·최대위치 | `x.sum()` / `x.mean()` / `x.max()` / `x.argmax()` (+ `axis=`) |
| 축 남기기 | `keepdims=True` |
| 반올림 | `x.round(1)` |
| 행/열 꺼내기 | `m[1, 2]` / `m[0]` / `m[:, 2]` |
| 조건 고르기 / 개수 | `a[a > 2]` / `(a > 2).sum()` |
| 두 조건 | `(a > 0) & (a < 6)` |
| 조건으로 바꾸기 | `np.where(조건, 참, 거짓)` |
| 분산 / 표준편차 | `x.var()` / `x.std()` (표본: `ddof=1`) |
| 제곱근 / 지수 | `np.sqrt(x)` / `np.exp(x)` |
| 거의 같은지 | `np.allclose(a, b)` / `np.isclose(a, b)` |
| 난수 | `rng = np.random.default_rng(seed)` → `rng.integers(1, 7, size=5)`, `rng.normal(70, 10, size=(1000, 3))` |
| 리스트로 되돌리기 | `x.tolist()` |
