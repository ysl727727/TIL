## 1. 미분은 "조금 움직여 보기"

모델 학습은 다이얼을 돌려서 틀린 정도(손실)를 줄이는 일이에요. **어느 쪽으로 돌려야 하는지** 알려 주는 도구가 미분이에요.

y = x²에서 x를 3 → 3.1로 움직이면:

```
          처음      움직인 뒤     움직인 양
x          3          3.1           0.1
y = x²     9          9.61          0.61

기울기 = y가 움직인 양 / x가 움직인 양 = 0.61 / 0.1 = 6.1
```

y가 x보다 약 6배 더 움직였고, 이 **배율이 기울기**예요. 속도도 기울기예요. 위치 변화를 시간 변화로 나눈 값이니까요.

```python
def f(x):
    return x ** 2

x = 3
h = 0.1                        # x를 움직인 양
before = f(x)                  # 처음 y
after = f(x + h)               # 움직인 뒤 y
print(round((after - before) / h, 4))   # 6.1
```

**외울 것**
- 기울기 = **Δy / Δx** = `(f(x + h) - f(x)) / h`

## 2. 조금만 움직일수록 정확해요

```python
for h in [1, 0.1, 0.01, 0.001]:
    print(h, round((f(x + h) - f(x)) / h, 4))
# 1 7.0
# 0.1 6.1
# 0.01 6.01
# 0.001 6.001
```

h를 줄일수록 값이 **6**에 다가가요. 이렇게 다가가는 값이 **극한**이고, 이 6이 x = 3에서의 미분값이에요. **f'(3) = 6**이라고 쓰고 "에프 프라임"이라고 읽어요.

그래프로 보면, h가 작을수록 두 점을 이은 선이 곡선에 딱 붙어요.

> **내가 헷갈렸던 것:** 왜 h가 작아야 정확할까?
> 곡선은 구간마다 기울기가 달라요. 멀리 떨어진 두 점을 이으면 그 사이 평균 기울기가 나와요. 두 점을 붙여야 **그 점에서의** 기울기에 가까워져요.

## 3. 기울기의 부호가 방향이에요

앞으로만 움직이는 대신 **양쪽으로 똑같이** 움직이면 더 정확해요. 이게 **중앙 차분**이에요. 두 점 사이가 `2 * h`라서 그만큼으로 나눠요.

```python
def slope_at(f, x):                # f 자리에 함수를 통째로 넘겨요
    h = 0.001
    return (f(x + h) - f(x - h)) / (2 * h)

print(round(slope_at(f, -2), 3))   # -4.0
print(round(slope_at(f, 0), 3))    # 0.0
print(round(slope_at(f, 2), 3))    # 4.0
```

- 괄호 없이 `f`라고 쓰면 **함수 자체**예요. 그래서 `slope_at`은 어떤 함수든 받아서 기울기를 재요.
- 분모 `(2 * h)`의 괄호는 꼭 써요. 없으면 `/ 2 * h`가 돼서 나누고 곱해 버려요.
- 한 줄 함수는 `lambda`로 바로 넘길 수 있어요. 아래 두 줄은 같은 뜻이에요.
  `slope_at(f, 5)` == `slope_at(lambda t: t ** 2, 5)` → `10.0`

곡선을 스치는 짧은 선이 **접선**이에요. 접선 기울기의 부호가 방향을 알려 줘요.

| 기울기 | 모양 | y를 줄이려면 |
|---|---|---|
| 음수 | 내리막 | x를 **오른쪽**으로 |
| 0 | 평평 | 그대로 |
| 양수 | 오르막 | x를 **왼쪽**으로 |

**외울 것**
- 중앙 차분: `(f(x + h) - f(x - h)) / (2 * h)`
- **기울기와 반대 방향**으로 가면 y가 줄어요 (다음 회차 경사하강법의 핵심).

## 4. 자주 쓰는 규칙 세 개 (도함수)

어느 x에서든 기울기를 알려 주는 식이 **도함수**예요.

| 함수 | 기울기 | 뜻 |
|---|---|---|
| 5 | 0 | 변하지 않으니 기울기가 없어요 |

| x² | 2x | x = 3이면 6, x = -2면 -4 |

def line(x):

## 5. 편미분 (설명으로 이해하기)

모델에는 다이얼이 여러 개예요. 둘을 같이 돌리면 누구 때문에 바뀌었는지 몰라요. 그래서 **하나만 움직이고 나머지는 그대로** 둬요. 이게 편미분이에요. 새로운 계산이 아니라, 1절의 계산을 다이얼마다 한 번씩 하는 거예요.

z = x² + 3y², x = 2, y = 1일 때:

```
                  x       y       z           z가 움직인 양   기울기
처음              2       1       7
x만 0.01 움직임   2.01    1       7.0401      0.0401          4.01  → 4
y만 0.01 움직임   2       1.01    7.0603      0.0603          6.03  → 6
```

- ∂z/∂x = 4, ∂z/∂y = 6. **∂는 "하나만 움직였다"는 표시**예요.
- 둘을 모은 **[4, 6]이 기울기 벡터(gradient)**예요. 가장 가파른 **오르막**을 가리켜요. 다음 회차에는 이 화살표의 반대로 내려가요.

> **내가 틀렸던 것:** x² + 3y²를 x로 편미분하면 2x + 3, y로 하면 1 + 6y라고 생각했음.
> → **틀림.** x로 편미분할 때 y는 고정이라 **3y²는 그냥 상수 → 0**이에요. 반대로 y로 할 때 x²가 상수라 0이에요.
> - ∂z/∂x = **2x** → x = 2면 4
> - ∂z/∂y = **6y** → y = 1이면 6
> 이게 위 표의 4, 6과 딱 맞아요.

## 6. 연쇄법칙 (설명으로 이해하기)

톱니바퀴처럼 계산이 이어져 있으면 **단계마다의 배율을 곱해요.**

```
        2배               3배
  x  -------->  g  -------->  y

  x가 1 움직이면 → g는 2 움직이고 → y는 6 움직여요
  전체 배율 = 2 × 3 = 6
```

y = (2x + 1)²을 x = 1에서 보면:

```
1단계  g = 2x + 1     x = 1 → g = 3     배율 2
2단계  y = g²         g = 3 → y = 9     배율 2g = 6
                                        전체 배율 = 2 × 6 = 12
```

2단계 배율에는 x = 1이 아니라 **2단계에 들어온 값 g = 3**을 넣어요.

```python
def two_steps(x):
    g = 2 * x + 1
    return g ** 2

print(round(slope_at(two_steps, 1), 3))    # 12.0
```

> **내가 헷갈렸던 것:** 왜 배율을 곱해? 왜 하필 "2"야?
> - g² 미분(2g = 4x + 2)까지는 이해했음. 그런데 그건 **"g가 1 움직이면 y가 얼마나"**까지예요.
> - 우리가 원하는 건 **"x가 1 움직이면 y가 얼마나"**예요. x가 1 움직이면 g는 2x + 1이라 **2만큼** 움직여요. 이 "2"는 1단계 식 2x + 1에서 x 앞의 숫자예요.
> - 그래서 g가 2배로 커져서 2단계로 넘어가고, 2단계는 그걸 다시 2g배로 키워요. **키운 걸 또 키우니까 곱하기**예요.
> - 결과: 2 × 2(2x + 1) = **8x + 4** → x = 1이면 **12** ✅

### 연습문제 (직접 낸 비슷한 문제 3개)

| 문제 | 1단계 배율 | 2단계 배율 | 전체 | 내 답 |
|---|---|---|---|---|
| (3x + 2)², x = 1 | 3 | 2(3x + 2) = 6x + 4 | 3 × (6x + 4) = **18x + 12 → 30** | ❌ 12x + 8 → 20 (1단계 배율을 3이 아니라 2로 곱함) |
| (x − 4)², x = 2 기울기와 방향 | 1 | 2(x − 4) = 2x − 8 | **2x − 8 → −4 → 오른쪽** | ⚠️ 식은 맞았는데 계산에서 −6 (2·2 − 8 = **−4**) |
| (5x + 1)², x = 0 | 5 | 10x + 2 | **50x + 10 → 10** | ✅ 전부 맞음 |

**실수에서 배운 것:** 1단계 배율은 **안쪽 식에서 x 앞의 숫자**예요. (3x + 2)면 3, (5x + 1)이면 5.

### 학습에 연결하기

예측 = w × x, 손실 = (예측 − 정답)², x = 2, 정답 = 5, w = 1이면:

```
w = 1 → 예측 2 → 오차 -3 → 손실 9

w에서 오차까지의 배율    = x = 2
오차에서 손실까지의 배율 = 2 × 오차 = -6
w의 기울기               = 2 × (-6) = -12  →  음수니까 w를 키우면 손실이 줄어요
```

이 곱셈을 모델 전체에 하는 게 나중에 배울 **역전파**예요.

**외울 것**
- 편미분 = **하나만 움직이기** (나머지는 상수 → 미분하면 0)
- 연쇄법칙 = **배율끼리 곱하기**, 바깥 배율에는 **그 단계에 들어온 값**을 넣기

## 7. sympy: 식을 미분해요

숫자 대신 **식**을 다루는 라이브러리예요. 손으로 구한 기울기 확인용으로 써요.

```python
import sympy as sp

x = sp.symbols("x")               # 숫자가 아니라 문자 x
d = sp.diff(x ** 2, x)            # x로 미분
print(d)                          # 2*x
print(d.subs(x, 3))               # 6
print(sp.diff((2 * x + 1) ** 2, x))        # 8*x + 4
```

**외울 것**
- `sp.symbols("x")`는 문자 만들기, `sp.diff(식, x)`는 미분, `.subs(x, 값)`은 대입, `float(...)`은 파이썬 실수로 바꾸기예요.
- 순서는 **미분 → 대입 → float**

def central_diff(f, x, h=0.001):

### 응용 3: `which_way`
```python
def which_way(slope):
    if slope > 0:
        return "왼쪽"
    elif slope < 0:
        return "오른쪽"
    else:
        return "그대로"
```
기울기의 **반대 방향**으로 가요.

### 심화 1: `is_correct_slope`
```python
def is_correct_slope(f, x, guess):
    actual = central_diff(f, x)
    return abs(actual - guess) < 0.001
```
- `abs`가 없으면 6 − 9 = −3 < 0.001이 True가 돼서 틀린 추측을 맞다고 해요.
- `==` 대신 허용 오차를 쓰는 이유: 잰 기울기는 5.999999처럼 아주 조금 어긋나요 (`np.isclose`와 같은 생각).

### 심화 2: `flattest`
```python
def flattest(f, points):
    best = points[0]
    for p in points:
        if abs(central_diff(f, p)) < abs(central_diff(f, best)):
            best = p
    return best

# 짧은 버전
# return min(points, key=lambda p: abs(central_diff(f, p)))
```
- 평평하다는 건 기울기의 **절댓값이 0에 가깝다**는 뜻이에요. abs를 빼면 가장 가파른 내리막(−3)을 골라 버려요.
- 돌려주는 건 기울기가 아니라 **x 값**이에요.

### 심화 3: `first_good_h`
```python
def first_good_h(f, x, answer, hs):
    for h in hs:
        slope = measure_slope(f, x, h)
        if abs(slope - answer) < 0.05:
            return h
    return None
```
| h | 잰 기울기 | 6과의 차이 |
|---|---|---|
| 1 | 7 | 1 ✗ |
| 0.1 | 6.1 | 0.1 ✗ |
| 0.01 | 6.01 | 0.01 ✓ → return |

- 문제에서 "기초 2로 잰다"고 했으니 중앙 차분이 아니라 **앞쪽 방식**을 써요.
- `return None`은 **for 밖에** 둬요. 안쪽 else에 넣으면 첫 h가 실패하자마자 None이 돼요.

### 실무 1: `sympy_slope`, 내가 쓴 코드 ✅
```python
def sympy_slope(expr, a):
    x = sp.symbols("x")
    d = sp.diff(expr, x)
    return float(d.subs(x, a))
```
- `x`를 함수 안에서 직접 만들어서 바깥에 의존하지 않아요. 그래서 더 안전해요.
- 테스트가 만든 x와 다른 변수인데도 동작하는 이유: sympy는 **이름이 같으면(`"x"`) 같은 문자**로 봐요.
- `(2x + 1)²`을 넣으면 sympy가 연쇄법칙까지 계산해서 `8x + 4` → 12가 나와요. 손으로 푼 답과 같아요.

| 가장 작은 것 찾기 | `best = 첫 값` → for → 더 작으면 바꾸기 / `min(..., key=...)` |
| 첫 번째로 만족하는 것 | for 안 `if 조건: return 값`, for 밖 `return None` |
| sympy 미분 | `sp.diff(식, x)` → `.subs(x, a)` → `float()` |
