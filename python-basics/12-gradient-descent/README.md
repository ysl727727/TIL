## 큰 흐름

```text
한 걸음 x − lr × 기울기 → 여러 걸음(기울기는 매번 새로) → 학습률(수렴 · 진동 · 발산)
→ 2차원(배열로 똑같이) → 직선 맞추기(MSE는 w, b의 함수) → w, b 기울기(연쇄법칙)
→ train / test 나눠 평가 → minimize · LinearRegression(같은 일을 라이브러리로)
```

## 1. 눈을 가리고 산을 내려가기

눈을 가리고 산에 서 있으면 전체 지도는 안 보이고 **발밑 경사만** 느낄 수 있어요. 그래서 경사가 내려가는 쪽으로 한 걸음 옮기고, 다시 경사를 재는 걸 반복해요. 이게 **경사하강법**이에요.

지난 회차에서 기울기(gradient)는 **오르막**을 가리킨다고 배웠어요. 내려가려면 그 반대로 가야 하니까 **기울기를 빼요.**

```
새 x = x - 학습률 × 기울기

기울기 양수 → x가 줄어요 (왼쪽으로)
기울기 음수 → x가 늘어요 (오른쪽으로)
기울기 0    → 그대로
```

- 빼기 하나로 방향이 저절로 맞아요. 지난 회차 `which_way`의 if문을 식 하나로 해결한 셈이에요.
- **학습률(lr)**은 한 걸음의 크기예요.
- 왜 굳이 걸어가냐면, 함수가 복잡하면 "기울기 = 0"인 곳을 식으로 바로 풀 수 없기 때문이에요. 하지만 기울기는 언제든 잴 수 있어요.

## 2. 1차원 경사하강법

f(x) = (x − 3)²의 바닥은 x = 3이에요. 기울기는 **연쇄법칙**으로 구해요. 안쪽 x − 3의 배율 1 × 바깥 g²의 배율 2g = **2(x − 3)**이에요.

```python
def f(x):
    return (x - 3) ** 2

def df(x):
    return 2 * (x - 3)

x = 0.0
lr = 0.1
for i in range(3):
    x = x - lr * df(x)
    print(i + 1, round(x, 3))
# 1 0.6
# 2 1.08
# 3 1.464
```

| 걸음 | 지금 x | 기울기 2(x − 3) | lr × 기울기 | 새 x |
|---|---|---|---|---|
| 1 | 0 | 2 × (−3) = −6 | −0.6 | 0 + 0.6 = **0.6** |
| 2 | 0.6 | 2 × (−2.4) = −4.8 | −0.48 | 0.6 + 0.48 = **1.08** |
| 3 | 1.08 | 2 × (−1.92) = −3.84 | −0.384 | 1.08 + 0.384 = **1.464** |

> **내가 물어본 것 ①: 기울기가 왜 −6, −4.8, −3.84야?**
> 기울기는 고정값이 아니에요. **지금 x를 df에 넣어서 매번 새로 계산**해요.
> x − 3은 **바닥까지 남은 거리**예요(3 → 2.4 → 1.92). 기울기는 그 2배라서, 가까워질수록 작아져요.
> x가 3보다 왼쪽에 있어서 x − 3이 음수예요. 그래서 기울기도 음수예요.
>
> **내가 물어본 것 ②: x가 왜 0.6, 1.08이야?**
> 학습률이 0.1이니까 **기울기의 10분의 1**만큼 움직여요. 기울기가 음수라 **빼기의 빼기 = 더하기**가 돼서 x가 커져요.
> 그렇게 나온 새 x가 다음 걸음의 "지금 x"가 돼요 (`x = ...`로 덮어쓰니까요).

**걸음이 0.6 → 0.48 → 0.384로 저절로 짧아지는 이유:** 학습률은 그대로인데, 바닥에 가까울수록 **기울기가 작아지기** 때문이에요.

경로를 기록할 때는 `path[-1]`(리스트의 마지막 값, 즉 지금 위치)로 다음 걸음을 계산해서 `append`해요.

## 3. 학습률: 작으면 느리고, 크면 튕겨 나가요

f(x) = x²에서 x = 5로 출발해요.

```python
def run_gd(df, x0, lr, steps):
    path = [x0]
    for i in range(steps):
        path.append(path[-1] - lr * df(path[-1]))
    return np.array(path)
```

x²에서 한 걸음은 `x - lr × 2x = (1 - 2 × lr) × x`예요. **걸음마다 x에 이 배율이 곱해져요.**

| 학습률 | 배율 | 5에서 출발 | 결과 |
|---|---|---|---|
| 0.01 | 0.98 | 5 → 4.9 → 4.802 | 천천히 줄어요 |
| 0.1 | 0.8 | 5 → 4 → 3.2 → 2.56 | 빠르게 줄어요 |
| 0.95 | −0.9 | 5 → −4.5 → 4.05 → −3.645 | 부호가 바뀌며 줄어요 (**진동**) |
| 1.05 | −1.1 | 5 → −5.5 → 6.05 → −6.655 | 부호가 바뀌며 커져요 (**발산**) |

- 배율이 **음수**면 매번 바닥을 넘어 반대편으로 가요. 그래서 튕겨요.
- 배율의 **크기가 1보다 작으면** 수렴하고, **1보다 크면** 발산해요.
- 줄이려는 함수의 값을 **손실**이라고 불러요. 손실 그래프가 **아래로 가면 수렴, 위로 가면 발산**이에요. 위로 가면 **학습률부터 줄여요.**
- `zip(axes, lrs)`는 두 묶음을 짝지어 하나씩 꺼내요.

## 4. 2차원 경사하강법: 화살표의 반대로

f(x, y) = x² + 3y²의 기울기는 **[2x, 6y]**예요(지난 회차 편미분). 식은 1차원과 똑같고 **위치와 기울기가 배열**일 뿐이에요.

```python
def grad2(v):
    return np.array([2 * v[0], 6 * v[1]])

v = np.array([2.5, 2.0])
for i in range(20):
    v = v - 0.1 * grad2(v)
print(v.round(3))         # [0.029 0.   ]
```

손으로 한 걸음 계산해 보면 이래요 (0단계 C).
```
[1, 1]에서 기울기 = [2, 6]
새 위치 = [1, 1] - 0.1 × [2, 6] = [0.8, 0.4]
```

- 배열이라 **x는 x끼리, y는 y끼리** 따로 계산돼요.
- 배율은 x 방향이 1 − 0.2 = 0.8, y 방향이 1 − 0.6 = 0.4예요. 가파른 y가 더 빨리 줄어요.
- 학습률을 0.3으로 키우면 y 방향 배율이 1 − 6 × 0.3 = **−0.8**이 돼요. 그래서 y 방향으로 **지그재그**를 그려요.
- **방향마다 가파른 정도가 다르면 학습률 하나로 모두 맞추기 어려워요.**

## 5. 직선 맞추기: 손실은 평균 제곱 오차(MSE)

점들에 가장 잘 맞는 직선 **y = wx + b**를 찾아요.

```python
rng = np.random.default_rng(0)
x = np.linspace(0, 5, 30)
y = 2 * x + 1 + rng.normal(0, 1, 30)     # 정답 직선 y = 2x + 1에 잡음

def line_loss(w, b):
    return ((w * x + b - y) ** 2).mean()

print(round(line_loss(0.5, 3), 3))       # 8.189  나쁜 직선
print(round(line_loss(2, 1), 3))         # 0.67   좋은 직선
```

**MSE = 예측 → 오차 → 제곱 → 평균**

0단계 D로 손으로 계산하면 이래요. x = [1, 2, 3], y = [3, 5, 7], w = 2, b = 0일 때:

| x | 정답 | 예측 2x | 오차 | 제곱 |
|---|---|---|---|---|
| 1 | 3 | 2 | −1 | 1 |
| 2 | 5 | 4 | −1 | 1 |
| 3 | 7 | 6 | −1 | 1 |

MSE = 3 / 3 = **1.0**

**왜 제곱하냐면**
- −3과 +3을 그냥 더하면 0이 돼서 안 틀린 것처럼 보여요. 제곱하면 9 + 9로 잡혀요.
- 크게 틀린 점을 더 무겁게 봐요. 오차 1은 1이 되고 오차 7은 49가 돼요.

**생각 전환:** 데이터 x, y는 **고정**이고 움직이는 다이얼은 **w, b**예요. 그러니까 MSE는 **w와 b, 두 변수의 함수**예요. 그러면 2차원 그릇에서 바닥을 찾는 문제와 똑같아져요.

## 6. 경사하강법으로 w와 b 찾기

```
error = w × x + b - y
loss  = error²의 평균

∂loss/∂w = (2 × error × x)의 평균
∂loss/∂b = (2 × error)의 평균
```

### 왜 이 식이 나오냐: 점 하나로 보기 (x = 3, y = 7, w = 2, b = 0)

예측은 6, 오차는 −1, 손실은 1이에요.

| | 1단계: 다이얼이 1 커지면 오차는? | 2단계: 오차가 1 커지면 손실은? | 곱하기 (연쇄법칙) |
|---|---|---|---|
| **w** | 예측 = w × **3** + b라서 **3 (= x)** 움직여요 | 2 × 오차 = −2 | 2 × (−1) × 3 = **−6** |
| **b** | 예측 = w × 3 + **b**라서 **1** 움직여요 | 2 × 오차 = −2 | 2 × (−1) × 1 = **−2** |

직접 재서 확인해 볼게요. w를 2 → 2.01로 바꾸면 예측은 6.03, 오차는 −0.97, 손실은 0.9409예요. 손실이 0.0591 줄었으니 −0.0591 / 0.01 ≈ **−6** ✅

### 점 3개면 점마다 구해서 평균

| x | 오차 | 2 × 오차 × x | 2 × 오차 |
|---|---|---|---|
| 1 | −1 | −2 | −2 |
| 2 | −1 | −4 | −2 |
| 3 | −1 | −6 | −2 |
| **평균** | | **−4** | **−2** |

- w 기울기는 x가 클수록 커요. x가 큰 점일수록 w가 예측에 주는 영향이 크기 때문이에요.
- b 기울기는 모든 점이 같아요. b는 모든 예측을 똑같이 1씩 올리기 때문이에요.

학습률 0.1로 한 걸음 가 볼게요.
- w = 2 − 0.1 × (−4) = **2.4**
- b = 0 − 0.1 × (−2) = **0.2**
- 예측은 [2.6, 5.0, 7.4], 오차는 [−0.4, 0, 0.4]
- MSE가 1.0에서 **0.107**로 줄었어요.

**예측이 정답보다 작으면** 오차가 음수, 기울기도 음수가 돼서 w와 b가 **커져요.** 식이 방향을 알아서 맞춰 줘요.

> **내가 물어본 것: w는 연쇄법칙 적용이고 b는 미적용이야?**
> → **아니요, 둘 다 연쇄법칙이에요.** 바깥 배율 **2 × 오차**는 같아요.
> 안쪽 배율은 **변수 앞에 곱해진 것**이에요. w 앞에는 x가 있고, b 앞에는 1이 있어요. × 1은 생략돼서 안 보일 뿐이에요.
> 예를 들어 (x + 1)²을 미분하면 2(x + 1) × 1이에요. 연쇄법칙을 안 쓴 것처럼 보이지만 쓴 거예요.

수업 코드는 이래요.
```python
w, b = 0.0, 0.0
lr = 0.005
for i in range(3000):
    error = w * x + b - y
    w = w - lr * (2 * error * x).mean()
    b = b - lr * (2 * error).mean()
print(round(w, 2), round(b, 2))    # 1.98 0.93   (손실 0.654)
```
- 정답 직선 2x + 1에 가까운 값이 나와요.
- 손실이 0이 안 되는 건 **잡음** 때문이에요.
- 지난 회차 미분(기울기, 편미분, 연쇄법칙)과 오늘 배운 경사하강법이 전부 이 몇 줄에 들어 있어요.

## 7. 학습에 안 쓴 데이터로 평가하기

시험 문제를 미리 보고 공부하면 점수를 믿을 수 없어요. 그래서 데이터를 **학습용(train)**과 **평가용(test)**으로 나눠요.

```python
idx = np.random.default_rng(1).permutation(len(x))
test_idx, train_idx = idx[:6], idx[6:]       # 평가용 6개, 학습용 24개
x_tr, y_tr = x[train_idx], y[train_idx]
x_te, y_te = x[test_idx], y[test_idx]
# 학습용 MSE 0.657, 평가용 MSE 0.679
```

0단계 E로 보면 이래요.
```
idx = permutation(5) = [2 4 3 0 1]
data = [10, 20, 30, 40, 50]
평가용 data[[2, 4]] = [30 50]
학습용 data[[3, 0, 1]] = [40 10 20]
```

- `permutation(n)`은 0부터 n−1까지를 무작위로 섞어요.
- x와 y는 **같은 번호로** 골라요. 짝(같은 학생의 공부 시간과 점수)이 유지돼야 하니까요.
- 평가용 MSE가 학습용과 **비슷하면** 처음 보는 데이터에도 통한다는 뜻이에요. 학습용만 훨씬 작으면 **외웠다는** 신호예요.
- **실수:** 섞지 않고 `x[:24]`, `x[24:]`로 자르기. 정렬된 데이터라서 평가용이 전부 x가 큰 점이 돼요.

## 8. 실무 코드: minimize와 LinearRegression

```python
from scipy.optimize import minimize

def loss(p):                             # p = [w, b]
    return ((p[0] * x + p[1] - y) ** 2).mean()

result = minimize(loss, x0=[0.0, 0.0])
print(result.x.round(2))                 # [1.98 0.93]
```
- 손실 함수와 시작점만 주면 최솟값을 찾아 줘요. 기울기 식을 안 주면 내부에서 차분으로 재요.
- 직선이 아닌 어떤 손실에도 쓸 수 있어요.

```python
X = x.reshape(-1, 1)          # (30,) → (30, 1)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=1)
model = LinearRegression()
model.fit(X_tr, y_tr)
print(model.coef_.round(2), round(model.intercept_, 2))   # [1.93] 1.01
pred = model.predict(X_te)
print(round(mean_squared_error(y_te, pred), 3))           # 0.94
```
- 모든 sklearn 모델은 **fit(학습)과 predict(예측)**로 똑같이 써요.
- `coef_`는 w(특성마다 하나라서 배열), `intercept_`는 b예요.
- `train_test_split`은 섞어서 나누기를 해 줘요. `random_state`는 seed예요.
- `reshape(-1, 1)`이 필요한 이유: sklearn은 **행 = 데이터, 열 = 특성**인 2차원만 받아요. 1차원을 넣으면 `ValueError`가 나요. `-1`은 개수를 알아서 맞추라는 뜻이에요.

**경사하강법, minimize, LinearRegression이 모두 같은 일을 해요.** 직접 만든 반복문이 라이브러리 안에서 돌아가는 일의 뼈대예요. 5주에 배우는 파이토치 학습 루프도 같은 모양이에요.

### 기초 2: `descend`
```python
def descend(df, x0, lr, steps):
    x = x0
    for i in range(steps):
        x = x - lr * df(x)
    return x
```
- 기울기는 걸을 때마다 **지금 위치 x로 새로** 재요. `df(x0)`라고 쓰면 틀려요.
- `return`은 for **밖**에 둬요.
- `steps = 0`이면 반복문이 안 돌아서 출발점이 그대로 나와요.

### 기초 3: `line_mse`
```python
def line_mse(x, y, w, b):
    return ((w * x + b - y) ** 2).mean()
```
| w, b | 오차 | MSE |
|---|---|---|
| 2, 1 | [0, 0, 0] | 0 |
| 2, 0 | [−1, −1, −1] | 1 |
| 0, 0 | [−3, −5, −7] | (9 + 25 + 49) / 3 = 83/3 |

### 응용 1: `descend_2d`
```python
def descend_2d(grad, start, lr, steps):
    v = np.array(start, dtype=float)
    for i in range(steps):
        v = v - lr * grad(v)
    return v
```
- `np.array(start, dtype=float)`이 하는 일은 세 가지예요. ① 리스트를 배열로 바꾸고 ② **복사본**을 만들어서 입력 start를 보호하고 ③ 실수형으로 만들어요.
- `v = start` 다음에 `v -= ...`처럼 제자리 빼기를 하면 start까지 바뀌어서 테스트가 깨져요.

### 응용 2: `mse_gradient`
```python
def mse_gradient(x, y, w, b):
    error = w * x + b - y
    dw = (2 * error * x).mean()
    db = (2 * error).mean()
    return dw, db
```
- w = 0, b = 0이면 오차는 [−3, −5, −7]이에요.
  - dw = (−6 − 20 − 42) / 3 = **−68/3**
  - db = (−6 − 10 − 14) / 3 = **−10**
- 쉼표로 return하면 튜플이 되고, `dw, db = ...`로 나눠 받아요.
- 마지막 테스트는 **중앙 차분**으로 재서 내 식과 비교해요. 편미분이 "하나만 움직이기"라는 걸 확인하는 거예요.

### 응용 3: `split_train_test`
```python
def split_train_test(x, y, test_ratio=0.25, seed=0):
    idx = np.random.default_rng(seed).permutation(len(y))
    n_test = int(len(y) * test_ratio)
    test_idx, train_idx = idx[:n_test], idx[n_test:]
    return x[train_idx], x[test_idx], y[train_idx], y[test_idx]
```
- `int(...)`: 슬라이싱에는 정수가 필요해요 (20 × 0.25 = 5.0 → 5).
- x, y를 **같은 번호로** 골라요. 테스트가 `x_tr * 10 == y_tr`로 짝을 확인해요.
- 반환 순서는 x_train, x_test, y_train, y_test예요 (sklearn과 같아요).

## 추가로 물어본 것: MSE · sigmoid · Cross Entropy · DPO

### sigmoid / BCE / Cross Entropy 차이

| | 종류 | 하는 일 |
|---|---|---|
| **sigmoid** | 함수 (확률 만들기) | 점수 하나를 0~1 확률로 바꿔요. `1 / (1 + e^(−z))` |
| **BCE** | 손실 | 예/아니오 문제를 채점해요 |
| **Cross Entropy** | 손실 | 여러 개 중 하나 고르는 문제를 채점해요 (softmax와 짝) |

- 손실은 **−log(정답 쪽 확률)**이에요. 0.9면 0.11, 0.5면 0.69, 0.1이면 2.30이에요. **자신 있게 틀리면 크게 혼나요.**
- BCE는 칸 2개짜리 Cross Entropy예요.

| 문제 | 확률 만들기 | 손실 |
|---|---|---|
| 숫자 맞히기 | 그대로 | **MSE** |
| 예/아니오 | **sigmoid** | **BCE** |
| 여러 개 중 하나 | **softmax** | **Cross Entropy** |

### DPO 손실 = 정답이 항상 1인 BCE

좋은 답 y_w와 나쁜 답 y_l이 있고, 점수는 r_w와 r_l이에요.

**BCE에서 출발하면:**
```
BCE = −[ y log p + (1−y) log(1−p) ]
       ↓  정답 y는 항상 1 (사람이 y_w를 골랐으니까)
     −log p
       ↓  p = sigmoid(r_w − r_l)
     −log sigmoid(r_w − r_l)          ← DPO 손실
```

**칸 2개 softmax가 sigmoid가 되는 이유:** 분자와 분모를 e^(r_w)로 나누면 나와요.
```
e^(r_w) / (e^(r_w) + e^(r_l)) = 1 / (1 + e^(−(r_w − r_l))) = sigmoid(r_w − r_l)
```

DPO의 점수는 **r = β × log(π_θ / π_ref)**예요. 학습 중인 모델이 기준 모델보다 그 답을 얼마나 더 좋아하게 됐는지를 뜻해요.

| r_w − r_l | sigmoid | 손실 |
|---|---|---|
| 2 | 0.88 | 0.13 |
| 0 | 0.5 | 0.69 |
| −2 | 0.12 | 2.13 |

### 계산 순서 (내가 헷갈렸던 것)

> **"CE(−log p)를 먼저 하고 그다음 sigmoid?"** → **반대예요.**
> 식 `−log( sigmoid( r_w − r_l ) )`을 **안쪽부터** 읽어요.
> ① 점수 차이 (3 − 1 = 2) → ② sigmoid로 확률 (0.88) → ③ −log로 손실 (0.13)
> - sigmoid가 **안쪽(먼저)**, −log가 **바깥(나중)**이에요. "−sigmoid"라는 단계는 없어요.
> - **식을 유도하는** 순서(CE에서 출발 → p를 sigmoid로 채움)와 **계산하는** 순서는 반대예요.
> - MSE도 같아요. 유도할 때는 "오차²의 평균"에서 출발하지만, 계산은 wx + b → 빼기 → 제곱 → 평균 순서예요.
>
> **파인튜닝 6장 코드와 헷갈리지 않기:** 실제 DPO 코드는 맨 앞에서 `-F.cross_entropy(...)`로 **토큰 log p를 꺼내요.** 그건 손실이 아니라 응답 점수(r)를 만드는 재료라서, 여기서 말한 "−log는 바깥(나중)"과 다른 단계예요. 전체 순서는 토큰 log p → 응답 점수 합 → reference와 비교(reward) → r_w − r_l → sigmoid → −log예요 → [파인튜닝 6장 DPO 손실 계산 순서](../../fine-tuning/06-dpo-preference-optimization/)

### 오늘 배운 MSE와 DPO의 연관성

**같은 틀:** 예측 → 손실 → 기울기 → 경사하강법

```
오늘:  w, b → wx+b ───────────────→ MSE → 기울기 2×(예측−정답) → 경사하강법
DPO:   θ   → r_w − r_l → sigmoid → CE  → 기울기 (p − 1)       → 경사하강법
```

- 기울기 모양이 둘 다 **"예측 − 정답"**이에요. 틀린 만큼 크게 고치고, 맞으면 0이에요.
- **sigmoid에 MSE를 붙이면 안 되는 이유:** sigmoid는 양 끝에서 평평해요. 그래서 완전히 틀렸을 때 기울기가 거의 0이 돼요.

| z = −5, p = 0.007 (나쁜 답을 훨씬 좋아함) | z로 미분한 기울기 |
|---|---|
| MSE (p − 1)² | ≈ −0.013 → 거의 안 고쳐요 |
| CE −log p | ≈ −0.99 → 세게 고쳐요 |

  CE의 −log가 sigmoid가 줄인 기울기를 상쇄해서, 깔끔한 **p − 1**이 나와요.
- 그래서 **숫자에는 MSE, sigmoid 확률에는 CE**를 써요.

| 하고 싶은 것 | 패턴 |
|---|---|
| 한 걸음 | `x - lr * slope` |
| 여러 걸음 | `x = x0` → for 안 `x = x - lr * df(x)` → for 밖 `return x` |

| 최솟값 찾기 | `minimize(loss, x0=[...]).x` |
| sklearn 직선 | `reshape(-1, 1)` → `fit` → `coef_`, `intercept_` → `predict` |

## 외울 것 (최종)
- **새 위치 = 위치 − 학습률 × 기울기.** 기울기를 빼니까 방향이 저절로 맞아요.
- 바닥에 가까울수록 기울기가 작아져서 걸음이 저절로 짧아져요.
- x²에서 한 걸음은 **(1 − 2·lr)배**예요. 크기가 1보다 작으면 수렴, 1보다 크면 발산, 음수면 진동해요.
- MSE는 w, b의 함수예요. 데이터는 고정이고 **w, b가 다이얼**이에요.
- w, b 기울기는 **둘 다 연쇄법칙**이에요. 안쪽 배율이 w는 x, b는 1이에요.
- 학습용과 평가용은 **섞어서** 나누고, **같은 번호**로 골라요. 평가는 학습에 안 쓴 데이터로 해요.
- DPO 손실 = **−log sigmoid(r_w − r_l)** = 정답이 항상 1인 BCE예요. 계산은 sigmoid 먼저, −log 나중이에요.
